# Thai Twist Shorts — agent rules

This repo makes Thai vertical (9:16) and landscape twist-ending short stories with **Remotion** (TSX).

**For any request about an episode — a new story idea, writing, scenes, voice, sound, review or render — invoke the `thai-twist-short` skill first** (`.claude/skills/thai-twist-short/SKILL.md`). For a landscape long-form episode (`"format": "landscape"`, 10–25 min) invoke `thai-long-story` instead (`.claude/skills/thai-long-story/SKILL.md`). Where a skill disagrees with this file, this file wins. Before planning shots or drawing scenes, read `.claude/skills/thai-twist-short/references/directing.md`: you are the director and art director of every frame.

## Hard rules

1. `episodes/<slug>/story.json` is the single source of truth. Never hand-edit generated files: `episodes/<slug>/timeline.json`, `assets/voice.wav`, `assets/score.wav`, `src/episodes/index.ts`, `src/cast/CastSprite.tsx`.
2. Run scripts from the repo root: `npm run <new|timeline|audio|voice|score|fit|story|coldread|shots|look|review|motion|chapter|check|qc|final|gallery|studio> -- episodes/<slug>`. `coldread` writes what a viewer hears, cut part-way, to `out/<slug>-coldread/` so a reader who has not seen the brief can guess the twist before any voice is made (`.claude/story/cold-read.md`); `shots` audits camera-setup variety (`.claude/skills/thai-twist-short/references/cinematography.md`); `motion` renders 4 moments of each shot that declares `data.motion` / `data.move` (or the shots you list) to check camera moves and animation without a video render; `look` measures light and depth on the Board frames (`references/depth-light.md`; `check` runs it at the end).
3. After any change: `npm run check -- episodes/<slug>` (tsc + story-check + Board frames in `out/<slug>-board/`), then open the frames and look. A passing check is not proof it looks right.
4. Do not render a video (`npm run final`, `remotion render`) until you have looked at stills of the scenes you changed and told the user what the frames show.
   - While editing, use `remotion still` / Board frames only; never render to "see how it looks".
   - Render the full video once, after the frames pass, to check timing, voice sync and captions over time. Skip per-chapter preview renders (`chapter --render`) unless the user asks for one or a chapter is in doubt; the single full render is the timing check.
   - Exception: the user explicitly asks for a render.
5. **One-pass review before the final render (no score loop):** `npm run review -- episodes/<slug> --board` renders only the Board frames that changed, collects every audit ✗ (`shots`, `look`, `story`) into one suspect list and writes `out/<slug>-review.html`, one page with every shot at a readable size. Gate: (a) tsc, `story`, `shots`, `look` ✗ fixed or answered in one line; (b) you open the **suspect and changed frames at full size** (never every frame, never contact sheets of 30), and fix what is wrong once; (c) the **user** scrolls the page once and flags odd shots, and you fix only those (one round per list). No 1–10 scoring, no "re-score until ≥ 8", no per-chapter loops. Then `npm run review -- episodes/<slug> --accept`. Details: `references/review.md` (long-form: `thai-long-story/references/review-long.md`). Spend frames where audits and the user point; a score average hides the one odd shot.
6. Shared things (cast, props, captions, kit components) live in `src/` — improve them there, never only inside one episode. What goes in the kit is what a second story would actually use: a piece written for one story stays in `src/episodes/<slug>/` until another story needs it, then it moves, with what is particular to the first story taken out.
7. Deterministic only: no `Math.random()`, `Date.now()` or network in components; use `rnd()` from `src/engine/anim.ts`.
8. Ask before anything outward-facing (publishing renders, pushing to a remote).
9. Do not delete an episode's `assets/` (paid voice/SFX) or untracked files without asking.
10. Only the character who is actually speaking moves their mouth. `talk` goes only on the actor whose id is the shot's `who`; everyone else on screen (listeners, the near end of a phone call, anyone during narration) gets a listening face that fits the moment (`worried`, `sad`, `shock`…), never `talk`. When the speaker is off screen (a phone voice, a recording, a voice from another room), nobody on screen talks. The speaker's face matches what they are saying. `src/kit/stage.tsx` mutes every non-speaker and `npm run story` warns on a stray `talk` — fix the warning in story.json, don't ignore it.
11. **Motorcycle & riding posture (shot `021` standard):** For any motorcycle riding or parked motorcycle scene across all future projects, use the global `<SideRoadSet>` and `<Motorcycle>` from `src/kit/places.tsx` (registered in `src/gallery.json` under `places`: `highway-road`, `motorcycle-ride`, `motorcycle-parked`). When any character is riding a motorcycle, always use `<Motorcycle rider={{shirt, pants, skin, hair, face, vest}} />` (the side-riding sitting posture established in `ghost-money` shot `021`). This fixes the bike and the rider's posture, not the camera: shoot it from any angle (low by the wheel, over the shoulder, headlight on the road, the mirror).
12. **Cast single source of truth:** `src/cast.json` is the SINGLE SOURCE OF TRUTH for character selection, metadata, heights, voice roles, and outfits. Always cast from active, non-retired characters in `src/cast.json` (`lead-male-A/B`, `lead-female-A/B`, `villain-male-A/B`, `father-A/B`, `mother-A/B`, `brother-A/B`, `sister-A/B`, `police-A/B`, etc.). Never use legacy retired characters (`man`, `woman`, `auntie`, `elder`, `M1`...`B1`, `din`, etc., marked `"retired": true`). `sit`, `crouch` and `lie` are drawn on the character's own symbol (`src/cast/Body.tsx`), `back` on the shared back view in their colours: write the actor string (`win@900 sit yaw=0.5 armR=hold prop=phone`), no pose symbol needs naming.
13. **Costume & identity stay the same on everything.** Standing, turned, sitting, crouching, lying, walking: the body poses come with the real costume by themselves (jacket, pockets, uniform, tattoos, hair), so an episode never re-draws a costume over a pose. What still takes the character's details by hand is whatever draws its own person: `Motorcycle rider`, `CarInterior`, a shot written as its own SVG. There, pass their colours and overlay their signature details from `src/cast.json`. A trait of one story (a numbered vest, a scar) goes in that episode's roster `extra`.
14. **You direct every shot** (`.claude/skills/thai-twist-short/references/directing.md`, both formats). Every camera shot is a picture you design, written first as its `note` in story.json (who does what with what, seen from where, lit by what), then built to match it. You choose the camera, size, angle, composition, set and light; any shot may be its own SVG/React component in `src/episodes/<slug>/` (the `what-if-studio` `dead-come-home` S1–S18 pattern), and `<Stage>` is a convenience, not a requirement. There is no class of "routine" shots built from a preset backdrop.
    - **Places, not backdrops:** build each recurring place once in perspective (interiors with `src/kit/room.tsx`: `makeRoom`, `RoomShell`, `RBox`, `standAt`) and shoot it from several positions — wide to learn the room, then medium, real close-ups (the head about half the frame, z ≈ 3–3.6 in 16:9), inserts, low and high angles. One flat elevation zoomed in and out is not coverage.
    - **Light from a source:** every set shot has a light you can point to in the frame (window, bulb, lamp, phone, headlight); mid-tones sink (`LightVeil`), the light pools, the face is the brightest thing near it, shadows run away from the light (`data.lightAt`, `CastShadow`). Bright is allowed; lit evenly from nowhere is not. The reveal is the darkest frame.
    - **No cardboard staging:** no character standing face-on with arms down at dead centre as the picture. Stage people doing something with something (sitting on the bed edge, crouched against a wall, back turned to a door, a hand on the bolt); the cast are front-facing sprites, so favour close-ups, inserts, over-the-shoulder, backs and silhouettes over full-body stands.
    - **Depth when the picture needs it:** midground / background / atmosphere in every set shot; a dark blurred foreground when there is a reason for one (watched, over the shoulder, trapped) — about a third of shots, not a blob stuck on every frame.
    - **Audits are questions, the picture decides:** `npm run shots` and `npm run look` print ✗ for missing notes, repeated framings, even light, shadow share; answer each ✗ on a shot you changed with a fix or one line of why. The line names what can be seen in the frame; "dark on purpose" alone is not an answer. Numbers passing on a flat frame is a fail; a good frame with a reason beats a number.
    - **Sound off, phone size, can you name it?** Before accepting a frame, name its picture in a few words of things you can see ("one rider on a road through graves", not "light in fog"). Every thing the `note` names is in the frame, a light shows what makes it and what it falls on, and the first three shots say who, where and what threat. Open those full size, not only on the contact sheet. Checklist: `directing.md` §7.1. Anything a person holds or wears is on their own body: count the hands, two per person. Never draw an arm or `<Hand>` beside a cast sprite; pose its own arm (`arm=r-phone`, `armR=…`), which removes the resting one, and add a missing pose to `cast.svg` (`hands-poses.md`). If a picture reads as strange, change the camera to one the sprites can do, don't patch the shapes.
15. **The gallery is a library to search, not a menu to order from.** Write the shot's `note` first (who does what, from where, in what light), then look for parts; when nothing fits the story, draw what the picture needs in the episode. Never bend a story to a set because its name matched. A place card shows one set from three camera positions and says what it tells, where to shoot it from, what not to use it for and which episodes really used it: read those, don't go by the name. Copying a card's framing is not directing. Rules 11–13 still hold for whatever you use: they fix *what* is drawn, never where the camera stands. A new piece goes in `src/gallery.json` with those same fields.

16. **Nobody sits on air.** Every `sit` has something visible under it: a chair (the `chairs` prop of `Actors` draws one that fits the pose, front-on or side-on from `yaw`), a bench, crate, bed or stool drawn in the set at the same height. Pure close-ups that cut above the hips need none. Sitting on the floor is `crouch`, not `sit`.

17. **One universe, stories that stand alone.** Every episode lives in the Khlong Mok universe (`universe/bible.md` = rules and map, `universe/canon.json` = facts a script can read). Before any outline or brief (`/create-story-*`, `/twist-idea`, `/twist-next`, `/twist-series`) read both and declare a link level 0–4; 0 is fine, and a story is never bent to fit a place or a canon character. Hard canon (world rules, who is alive or dead, what already happened, the order of events) is never contradicted: change the story, or ask the user to change canon. Every episode must make sense watched alone: its main mystery closes inside it and never answers another episode's. A canon character's face and voice belong to them only (`lead-*` faces reuse freely as different people with new name, `extra` and voice). A new place that matters (the story turns there, it can hold another story, or a canon character works there) is added to `canon.json → places` with its set file, the cameras that worked and what it can tell, so later stories can shoot it again; when a second story uses it, it moves into `src/kit/` and `src/gallery.json` (rule 6). Canon changes only with the user's yes, written in the same turn as the approved outline or brief.

## Layout

```
src/
  index.ts, Root.tsx          registers <Id>, <Id>Board per episode + Cast / Faces / Props / Sets stills
  engine/                     story.ts (story.json -> shots), episode.tsx (defineEpisode), anim.ts, fonts.ts, theme.ts
  kit/Captions.tsx            captions with [gold] / {red} marks
  cast/                       CastSprite.tsx (GENERATED from source/cast.svg by scripts/svg-to-tsx.mjs), Sprite.tsx
  Gallery.tsx, GalleryPlaces.tsx   gallery compositions (GalleryPlaces: places from three cameras, parts on a plate)
  episodes/index.ts           GENERATED registry; <slug>/scenes.tsx (optional) = {sceneName: ShotComponent}
scripts/                      timeline, voice, score, sfx, fit, qc, story-check, check, finalize, new-episode, gallery, svg-to-tsx
studio/                       static gallery (index.html + manifest.js, generated by npm run gallery)
templates/story.json          starting story for npm run new
episodes/<slug>/              story.json, assets/ (voice, score, vo cache), timeline.json, renders/
public/                       fonts + <slug>/voice.wav, score.wav (linked by npm run timeline)
series/<name>.md              series bible (a series sits inside the universe)
universe/                     bible.md (world rules, map, link levels, place keeping) + canon.json (places, characters, events, threads, episodes)
retired/kit/                  drawings out of the library and out of the bundle, kept as reference
sfx-library/                  cached ElevenLabs SFX
```

## Commands

- `npm run dev` — static gallery at http://localhost:3431/studio/index.html (run `npm run gallery` when cast/kit images need refreshing). `npm run studio` — Remotion Studio on :3430.
- `npm run gallery` — renders reusable asset library (Cast, Places, Sets, Props, Poses, UI, Grades). Excludes episode board stills by default for maximum speed. Pass `--boards` or `--boards --episode=<slug>` if board stills are needed.
- `npm run archive <slug>` — archives completed episodes out of active Remotion bundling into `archive/<slug>/` (keeps bundling instant ~2s and prevents workspace bloat). Use `npm run archive -- --list` to view episodes or `npm run archive -- --restore <slug>` to reactivate.
- Gallery content: cast in `src/cast.json`, item lists in `src/gallery.json` (`faces`, `talk`, `rig` for every pose, `props`, `places`, `parts`, `inserts`, `camera`, `grades`, and `retired`, what left the library and why; compositions in `src/Gallery.tsx`, `src/GalleryPlaces.tsx`). Voice roles in `voices.json`. `npm run voices` makes the voice previews (ElevenLabs credits; only changed lines). `npm run voice-list` searches your ElevenLabs voices.
- Thinking helpers live as project skills: `/twist-idea`, `/twist-next`, `/twist-hook`, `/twist-series`, `/twist-ref`, `/twist-doctor`, `/twist-cast`. They end at an approved outline or a report; building goes through `thai-twist-short`.

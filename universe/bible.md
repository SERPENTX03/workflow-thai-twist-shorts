# จักรวาล "คลองหมอก" — universe bible

สถานะ: **ร่าง รอผู้ใช้อนุมัติ** (2026-11-09) · ไฟล์นี้คือกติกาและแผนที่ · ข้อเท็จจริงที่เครื่องตรวจได้อยู่ใน `universe/canon.json`
หลักใหญ่: **เชื่อมที่ข้อเท็จจริงของโลก ไม่เชื่อมที่โครงเรื่อง** ทุกเรื่องดูเดี่ยวๆ ได้ ตัวเอกเปลี่ยนได้ สถานที่เปลี่ยนได้ ตราบใดที่ไม่ขัดชั้นตายตัว

## 1. สองชั้น

| ชั้น | อะไรอยู่ในนี้ | เปลี่ยนได้ไหม |
|---|---|---|
| **ตายตัว (hard canon)** | กฎของโลก, สถานที่ศูนย์กลาง, ตัวละคร canon และสถานะ (ตาย/รอด), เหตุการณ์ที่เกิดแล้ว, ปีหรือช่วงเวลา | ไม่ (แก้ได้ต่อเมื่อผู้ใช้ตัดสินเอง และต้องไล่แก้ทุกเรื่องที่อ้างถึง) |
| **ลอย (per-episode)** | ตัวเอก, ภัย, ธีม, โทน, สถานที่เฉพาะเรื่อง | เต็มที่ |
| **คลุมเครือโดยตั้งใจ (soft)** | ที่มาของสิ่งลี้ลับ, ใครอยู่เบื้องหลัง, คำตอบของ open thread | ยังไม่ตอบ เก็บไว้ให้เรื่องหลังเฉลย |

## 2. ระดับการเชื่อม (ทุกเรื่องต้องประกาศ 1 ระดับ)

0. **เดี่ยวจบ** ไม่อ้างอะไรเลย (ยังต้องไม่ขัด hard canon)
1. **ไข่อีสเตอร์** ของ/ป้าย/เสียงวิทยุ โผล่ฉากหลัง คนไม่รู้ไม่เสียอะไร
2. **ตัวประกอบข้ามเรื่อง** หน้าเดิม เสียงเดิม (ตำรวจ, ฯลฯ)
3. **เหตุการณ์ร่วม** พูดถึงเหตุที่เกิดในอีกเรื่อง (ข่าว วิทยุ คำเล่าลือ)
4. **ภาคต่อตรงๆ** เฉพาะเรื่องที่ตั้งใจเป็นซีรีส์ (ใช้ series bible ใน `series/`)

เป้าหมายสัดส่วน: ส่วนใหญ่ระดับ 0–2, ระดับ 3 บางเรื่อง, ระดับ 4 เฉพาะซีรีส์. กฎเหล็ก: **ปมหลักของเรื่องปิดในตัวเอง** ไม่เฉลยปมของเรื่องอื่น ไม่ต้องดูเรื่องก่อนก็เข้าใจ

หมายเหตุ: ตารางนี้ทาบทับเรื่องที่ทำแล้วโดยไม่แก้ story.json เก่า การจับคู่ที่ยังไม่แน่ใจมาร์ก `(เดา)` ใน `canon.json`. สถานที่ใหม่ต้องเพิ่มที่นี่ก่อน แล้วค่อยใช้

### 3.1 เก็บสถานที่สำคัญไว้ใช้กับเรื่องต่อไป

เรื่องใหม่อยู่คนละที่กับเรื่องเก่าได้เสมอ ไม่ต้องย้ายเรื่องไปที่เดิม แต่สถานที่ที่เรื่องสร้างขึ้นมาต้องตัดสินว่าจะเก็บไว้ไหม

**เก็บเมื่อมีอย่างน้อย 1 ข้อ:** เรื่องพลิกที่นั่น (twist, reveal, จุดตาย) · มันใส่เรื่องอื่นได้อีก (ที่สาธารณะ ทางผ่าน ที่ทำงาน ร้าน วัด โรงพยาบาล) · ตัวละคร canon ทำงานหรืออยู่ที่นั่น
**ไม่เก็บ:** ที่ที่มีแค่ช็อตผ่าน ห้องที่ไม่มีลักษณะเฉพาะ ของที่วาดแค่ insert

**วิธีเก็บ (ใน `canon.json → places`):**
- `name` ชื่อบนจอ · `zone` อยู่ตรงไหนของอำเภอ (ริมคลอง / ตัวอำเภอ / ถนน 11 / ทางหลวง / ชานเมือง / ฯลฯ)
- `set` ไฟล์ที่วาด (ถ้าเรื่องถูก archive ไฟล์อยู่ที่ `archive/<slug>/src/…`)
- `cams` มุมกล้องที่ใช้ได้ดี (view ใน story.json ที่ผ่าน review) · `tells` ที่นี่เล่าอะไรได้ · `state` สภาพล่าสุด (ไหม้ ปิด ทาสีใหม่ ใครย้ายออก)
- `episodes` เรื่องที่ใช้ และ `keep: true`

**เมื่อเรื่องที่สองใช้ที่เดิม:** ย้ายตัวฉากเข้า `src/kit/` เอาสิ่งที่เฉพาะเรื่องแรกออก (กฎ 6) เพิ่มการ์ดใน `src/gallery.json` (`good`, `cams`, `bad`, `uses`) แล้วเปลี่ยน `set` ใน canon ให้ชี้ไปที่ kit. สภาพสถานที่ต้องตรงกับ `state` และเวลาที่เรื่องเกิด (ห้อง 808 หลังไฟไหม้ต้องดำ)
**ตอน archive:** `npm run archive` ย้าย `src/episodes/<slug>` ไป `archive/<slug>/src` ให้แก้ `set` ของสถานที่ที่ `keep: true` ให้ชี้ไปที่ใหม่ (หรือ promote เข้า kit ก่อน)

## 4. ตัวละคร canon (เริ่มเล็ก ไม่เกิน 5)

| id | บทบาท | หน้า/เสียง | จุดสังเกต (ตามได้) | สถานะ |
|---|---|---|---|---|
| `wichai` | **ร.ต.อ.วิชัย (หมวดวิชัย)** ร้อยเวร สภ.คลองหมอก | `police-A` · voice role `officer` | ไฝที่แก้มขวา (จาก `cast.json`) · สมุดปกดำ · แว่นกรอบดำ | มีชีวิต |

กติกาของหมวดวิชัย (ตัวเชื่อมของจักรวาล):
- ปรากฏเป็นตัวประกอบ **ไม่เคยเป็นผู้แก้คดีบนจอ** ตัวเอกของเรื่องเป็นคนไขปม หมวดมาถึงทีหลัง หรือรับเรื่องแล้วไม่เชื่อ
- เขารู้น้อยกว่าคนดูเสมอ
- เส้นเชื่อมช้าๆ ของเขา: เริ่มสังเกตว่า "คดีแปลกในอำเภอนี้มีของซ้ำ" (เห็นจากสมุดปกดำ/บอร์ดหลังโต๊ะ) ใช้เป็นระดับ 1–3 ไม่ต้องเฉลยว่าเป็นอะไร
- ห้ามฆ่าหรือให้เป็นผู้ร้ายโดยไม่ผ่านการอนุมัติ ตัวละคร canon อื่นเพิ่มได้ต่อเมื่อเรื่องต้องการจริง

ตัวเอกและตัวร้ายประจำเรื่องใช้ `lead-*`, `villain-*` ซ้ำหน้าได้ ถือเป็น "นักแสดงประจำ" คนละคนกับเรื่องอื่น ต้องเปลี่ยนชื่อ + ลักษณะเด่นใน roster `extra` + เสียงไม่ซ้ำเรื่องที่อยู่ติดกัน. อย่าใช้หน้าของตัวละคร canon เป็นตัวเอกอื่น

## 5. กฎของโลก (ร่าง · ตั้งใจเขียนให้กว้าง)

1. สิ่งลี้ลับในอำเภอนี้ **ตามกฎและราคาเสมอ** ทุกเรื่องมีกฎของมัน และผู้ฝ่ากฎต้องเสียอะไรสักอย่าง
2. คนในเรื่อง **ไม่รู้** ว่ามีเรื่องอื่นเกิดในอำเภอเดียวกัน ยกเว้นผ่านข่าว/ข่าวลือ
3. เรื่องแต่ง: ทุกเรื่องขึ้นการ์ด "เรื่องแต่ง" ตามเดิม ห้ามอ้างสถานที่จริง
4. ความผิดมักเป็นของ "คน" ที่จับต้องได้ แม้มีสิ่งเหนือธรรมชาติ (ตามแนวเรื่องที่ทำไปแล้ว)
5. (ผู้ใช้เพิ่ม/แก้ได้ ที่นี่คือที่เดียวที่กฎโลกถูกเขียน)

## 6. ไทม์ไลน์

ไม่ตรึงปีจริง ใช้ลำดับสัมพัทธ์ใน `canon.json` (`era`) เช่น `T0` = ช่วงที่เรื่องแรกเกิด, ค่าเป็นปีสัมพัทธ์ (`-3` = 3 ปีก่อน). เรื่องที่อ้างเหตุการณ์ของอีกเรื่องต้องอยู่หลังเหตุการณ์นั้น

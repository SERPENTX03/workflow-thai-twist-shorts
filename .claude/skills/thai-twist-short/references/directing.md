## 0. ทำไมภาพของเราแข็ง (หลักฐาน)

`same-child` 400 ช็อต **ผ่านโควตาเก่าทุกข้อ** (`npm run shots` เคยขึ้น "all variety checks pass") แต่ contact sheet ยังดูเป็นภาพเดียวกันทั้งเรื่อง: ผนังไม้หน้าตรง ตัวละครยืนหน้าตรงเต็มตัว แสงสีน้ำตาลเท่ากันทั้งห้อง สาเหตุไม่ใช่ฝีมือวาด แต่เป็น **ระบบที่เราสั่งให้ทำ**:

| สาเหตุ | ในระบบเก่า | ผลบนจอ |
|---|---|---|
| 1. ช็อต = พารามิเตอร์ของ backdrop | 69 ช็อตใช้ scene `rumpai`, 60 ช็อตใช้ `mali`; ช็อตหนึ่ง = scene + `view` + `data.cam` + actor string | ทุกช็อตของห้องนั้นคือภาพเดียวกันที่ zoom/เลื่อน; `rumpai:tonroom` กรอบเดียวกัน 10 ครั้ง |
| 2. ฉากเป็นภาพด้านหน้า (elevation) | `Stage` = โลกด้านข้างที่มีเส้นพื้น `FLOOR` เส้นเดียว ผนังขนานกับจอ แล้วแปะ `PerspFloor`/`SideWall` ทับทีหลัง | กล้องเข้าไป "ในห้อง" ไม่ได้ ได้แค่ส่องโปสเตอร์ใกล้ขึ้น มุมต่ำ/สูงเป็นแค่ชื่อ |
| 3. "close" ไม่ใกล้จริง | auto-close ของ `Stage` และ S4 เดิม = z 1.75–1.9 | ได้ภาพครึ่งตัว (ซึ่ง what-if เรียกว่า medium) — ไม่มีหน้าเต็มจอ ไม่มี ECU ที่ตาหรือมือ |
| 4. กฎเป็นโควตาและคำต่อท้าย | `-low` `-fif` ต้องมีกี่ช็อต, EYE ≤ 40 %, FG 20–35 % ทุกช็อตระทึก, เงา ≥ 60 % | AI ตั้งชื่อ view ให้ผ่าน audit, แปะก้อนเบลอดำที่ขอบจอให้ครบ "FG" — ตัวเลขผ่าน ภาพไม่ดีขึ้น |
| 5. แสงเป็นเกรดทั้งเฟรม | `Grade night/dim/noir` หรี่ทั้งภาพ + `Glow` ใหญ่ | มืดเท่ากันทั้งห้อง ไม่มีแอ่งแสง ไม่มีมุมมืด แสงไม่ได้มาจากอะไร |
| 6. Gallery กลายเป็นเมนู | CLAUDE.md บอก "routine = gallery set + preset `-wide -med -ots -close`" และ "custom ได้เฉพาะช็อตระทึก" | ช็อตส่วนใหญ่ถูกบังคับเป็น backdrop สำเร็จรูป ความคิดของผู้กำกับเหลือแค่ช็อตไคลแมกซ์ |
| 7. ตัวละครยืนเต็มตัวเสมอ | "full figures ≥ 600 px", px-per-cm เดียวต่อช็อต, sprite หน้าตรง | หุ่นกระดาษกลางห้อง; การแสดงไม่มี เพราะไม่มีอะไรให้มือ/ตัวทำ |

what-if ไม่ได้มีกฎมากกว่าเรา (look.md 92 บรรทัด) — ต่างกันที่ **วาดทีละภาพ**: ทุกช็อตมีประโยคบอกภาพ (`note`), ทุกช็อตเป็นคอมโพเนนต์ของมันเอง, ฉากเป็นห้องสามมิติที่กล้องเข้าไปได้, แสงมาจากของที่เห็น แล้ว veil กดโทนกลางลง

## 1. ลำดับคิดของผู้กำกับ (ทำทีละช็อต)

1. **ประโยคนี้ทำให้คนดูรู้สึก/รู้อะไร** — ไม่ใช่ "ฉากนี้อยู่ห้องไหน"
2. **ภาพเดียวที่บอกสิ่งนั้นโดยไม่ต้องมีเสียง** — เขียนเป็น `note` หนึ่งประโยค: *ใคร ทำอะไร กับอะไร มองจากที่ไหน แสงมาจากไหน*
3. **ขนาดภาพและมุม** ตามสิ่งที่ภาพต้องโชว์ (ข้อ 2) — มือที่สั่น = insert, ความโดดเดี่ยว = กว้างมาก, ใครมีอำนาจ = มุม
4. **แสง** ที่ทำให้สิ่งนั้นเด่นที่สุดในเฟรม (ข้อ 4)
5. **สร้าง**: เลือกชิ้นจาก kit ที่ช่วย หรือเขียนเองทั้งช็อต — kit เป็นอะไหล่ ไม่ใช่แม่แบบ

ถ้าข้อ 2 เขียนไม่ออก ช็อตนั้นยังไม่พร้อมวาด — ห้ามแก้ด้วย "ยืนสองคน two-shot ไปก่อน"

ตัวอย่าง `note` ที่ดี (จาก dead-come-home): *"ประตูไม้จากด้านใน สั่นทุกครั้งที่เคาะ แสงเย็นลอดใต้ประตู มีเงาเท้าสองข้าง"* · *"มุมพื้น macro: ช่องใต้ประตู แสงเย็น เงาเท้าซีดขยับน้ำหนัก"* · *"ข้ามไหล่ที่มืดเบลอ มือเขาเอื้อมไปที่กลอน หยุด แล้วชักกลับ"*
ตัวอย่างที่ไม่ใช่ภาพ: *"ภาคคุยกับมะลิ"* · *"ห้องนอน กลางคืน"* · *"two-shot"*

## 2. Shot list = ลำดับภาพ ไม่ใช่ลำดับ preset

- ทุกช็อตกล้อง (ไม่ใช่การ์ด) มี `"note"` ใน story.json ก่อนวาดอะไร (`npm run shots` เตือนช็อตที่ขาด)
- **ลำดับของสถานที่หนึ่ง** (coverage): เปิดด้วยภาพที่บอกภูมิศาสตร์ (ใครอยู่ตรงไหน แสงอยู่ตรงไหน ทางเข้าอยู่ตรงไหน) แล้วค่อย **เข้าไปข้างใน**: medium → close → insert ของสิ่งที่ประโยคพูดถึง → ปฏิกิริยา ตัดกลับไปกว้างเมื่อสถานการณ์เปลี่ยน
- **ทุกคัตเปลี่ยนขนาดภาพหรือมุม** — เพื่อนบ้านสองช็อตห้ามขนาด+มุมเดียวกัน (กฎเดียวที่บังคับ เพราะมันคือ jump cut)
- **ไม่ต้องเห็นทุกคนทุกช็อต** บทสนทนาไม่จำเป็นต้องเป็น two-shot: คนพูด close, คนฟัง close, มือ, ของ, ข้ามไหล่ — คนดูต่อภาพเองได้
- **เสียงนำภาพได้**: ประโยคของคนที่ไม่อยู่ในเฟรม = ภาพของสิ่งที่เขาพูดถึง หรือหน้าคนฟัง (CLAUDE.md ข้อ 10: คนในเฟรมห้ามขยับปาก)
- ช็อตซ้ำกรอบเดิมใช้ได้ **เมื่อตั้งใจ**: เบาะแสกรอบเดิมทุกครั้ง, mirror framing ตอนเฉลย (`cinematography.md` A2, A5) — เขียนใน `note` ว่าซ้ำช็อตไหน

### ขนาดภาพ — วัดจากผลบนจอ ไม่ใช่จากชื่อ

| ขนาด | ผลบนจอ | 16:9 (คนสูง ~480 px ที่ z 1) | 9:16 |
|---|---|---|---|
| Establishing / wide | ห้องทั้งห้อง ตัวละครเล็ก ≤ 1/3 ความสูงเฟรม, เห็นแสงและทางเข้า | z 0.8–1.1 | ตัวละคร 400–700 px |
| Medium | เอวขึ้นไป | z 1.6–2 | หัว+ลำตัว เต็มความกว้าง |
| **Close** | **หัวสูงราว 40–55 % ของเฟรม** | **z 3–3.6** | หัว ≥ 600 px |
| Extreme close / ECU | ตา ปาก มือ เต็มเฟรม | z 4–5 | ตา/มือ ≥ 900 px |
| Macro insert | วัตถุ 40–60 % ของเฟรม, BG มืดหรือเบลอ | วาดใหญ่เอง ไม่ใช่ zoom sprite | วาดใหญ่เอง |

`Stage` จะ auto-close ที่ z 1.75 ถ้าไม่ใส่ `data.cam` — นั่นคือ medium ช็อตที่ตั้งใจให้เป็น close **ต้องตั้ง cam เอง**

## 3. ฉากคือสถานที่ที่กล้องเดินเข้าไป ไม่ใช่ฉากหลังที่ถ่ายหน้าตรง

- **สร้างแต่ละสถานที่ครั้งเดียว แล้วถ่ายหลายมุม** — ภายในใช้ room kit (`src/kit/room.tsx`, gallery `room-wide` / `room-close`):
  ```tsx
  const R = makeRoom({x: 700, y: 470}, {x0: 520, x1: 1500, y0: 220, y1: 760}, 3.4); // VP, กล่องผนังหลัง, ความลึก
  <RoomShell r={R} id="s12" />                                   // เพดาน ผนังข้าง พื้น ผนังหลัง ลายไม้วิ่งเข้า VP
  <RFace r={R} pts={[[0.62,0.2,0],[0.86,0.2,0],[0.86,0.55,0],[0.62,0.55,0]]} fill="#8fb0d8" />   // หน้าต่างบนผนังหลัง
  <RBox r={R} u={[0.04,0.4]} v={[0.82,1]} w={[0.12,0.6]} front="#4a3020" top="#d8d2c4" />        // เตียง (มีเงาสัมผัสให้)
  const s = standAt(R, 0.7, 0.45);                               // เท้าของคนที่ยืนที่ (u, w) → cast "who@x,y"
  roomPxPerCm(R, 0.45)                                           // px-per-cm ที่ระยะนั้น → คนไกลเล็ก คนใกล้ใหญ่ อัตโนมัติ
  <LightVeil id="s12" lights={[[x, y, r]]} o={0.45} />           // กดโทนกลาง เหลือแอ่งแสง
  ```
  แล้วแต่ละช็อตแค่ย้ายกล้อง (`data.cam` หรือ `camT`) — ห้อง หน้าต่าง แสง เฟอร์นิเจอร์ยังอยู่ที่เดิมและถูก perspective ทุกมุม
- **วาง VP ไม่ตรงกลาง** และเปลี่ยน VP ต่อสถานที่ได้ (มุมห้อง = VP ใกล้ขอบ); มุมต่ำ = `vp.y` ต่ำลงใกล้พื้น, มุมสูง = `vp.y` สูง เห็นพื้นมาก — ทำ view ใหม่ของห้องเดิมด้วย `makeRoom` อีกตัวที่ VP ต่าง ไม่ใช่แค่ zoom
- **โลกต้องเต็ม**: ภาพกว้างมี ≥ 15–20 ชิ้นที่ออกแบบ (ชั้นวาง ปฏิทิน พัดลม หม้อข้าว ผ้าขาวม้า ปลั๊กพ่วง ศาลพระภูมิ) ไม่มีผนังโล่ง ทุกอย่างที่ตั้งบนพื้นมีขาและเงาสัมผัส
- **ฉากเก่า (`WoodRoom`, `Classroom`, `ShopRow`…) ยังใช้ได้** เป็น establishing หรือฉากหลังเบลอของ close-up; ถ้าสถานที่หนึ่งต้องถ่ายเกิน ~6 ช็อต ให้สร้างใหม่เป็นห้องสามมิติ แล้วย้ายเข้า `src/kit/` (CLAUDE.md ข้อ 6)
- **Gallery คืออะไหล่และไม้บรรทัด** — คนยืนกลางการ์ดมีไว้เทียบขนาด ไม่ใช่องค์ประกอบภาพ ไม่มีช็อตไหนต้อง "หน้าตาเหมือนการ์ด gallery"

## 4. แสงทำงานครึ่งหนึ่งของภาพ

- **แสงทุกดวงมาจากของที่เห็นได้**: หน้าต่างที่มีพระจันทร์/แดด, หลอดไฟห้อย, ตะเกียง, จอมือถือ, ทีวี, ประตูที่เปิดสู่ห้องสว่าง, เทียน, ไฟหน้ารถ
- **ผนังโทนกลางค่อนมืด** (ไม่ใช่น้ำตาลอ่อนสว่าง) เพื่อให้แสงอ่านออก แล้ว `LightVeil` กดโทนกลางลงอีก เหลือ **รู** ตรงที่แสงตก: รูขนาดเท่าแอ่งแสงจริง (รูเท่าผนังทั้งผนัง = แบนอีก) ค่า `o` ~0.3 สำหรับภาพกว้างที่ต้องเห็นพื้น, 0.4–0.55 ที่อื่น (Stage `Grade` ยังหรี่ทับอีกชั้น — ลด `o` ถ้าใช้เกรดกลางคืน)
- **ตัวละครเด่นที่สุดในบริเวณของเขา**: หน้าสว่าง/คมที่สุด, rim ฝั่งที่หันเข้าแสง, ไม่มีแขนขามืดจมผนังมืด; ของที่สว่างกว่าหน้า (ตู้เย็นขาว ผ้าปูที่นอนขาว) ลดลงหนึ่งขั้น
- **ฝุ่นในลำแสง หมอก bokeh** ทำให้มีชีวิตแม้ตัวละครนิ่ง
- **กลางวันก็ต้องมีทิศ**: สว่างได้ แต่แสงเข้ามาด้านเดียว มีด้านมืด มีเงา
- ความมืดตามอารมณ์ยังเป็นแนวทาง (`depth-light.md` §4) แต่ **ดูจากภาพ** — `npm run look` เป็นเครื่องวัดช่วยหา ไม่ใช่ข้อสอบ

## 5. การแสดงและการวางตัว (Staging)

- **ตัวละครทำอะไรกับอะไรเสมอ**: นั่งขอบเตียง กอดเข่าพิงผนัง ก้มเก็บของ ถือโทรศัพท์ส่องหน้า เปิดลิ้นชัก ยืนหันหลังมองประตู — ไม่ยืนแขนแนบตัวกลางห้อง
- **วางตามพื้นที่ของห้อง** (`standAt(R, u, w)`) ไม่ใช่ตามเส้นพื้นเส้นเดียว: คนหนึ่งใกล้กล้อง คนหนึ่งไกล = ความลึกและอำนาจ (`cinematography.md` A3)
- **ตัวละครแทบไม่ต้องขยับ** ชีวิตมาจากรอบตัว: หน้าเปลี่ยนตามจังหวะ (กะพริบตาตอนเปลี่ยนสีหน้า), มือเปลี่ยนท่า, push-in ช้า, ฝุ่น ไฟกะพริบ ผ้าม่านไหว
- **ข้อจำกัดของ cast ตอนนี้: sprite หน้าตรง** (ยังไม่มี rig หัน 3/4 แบบ what-if) จึงต้องกำกับให้ไม่โชว์จุดอ่อน: ใช้ close/ECU, insert มือ, ข้ามไหล่ (ไหล่ FG ใหญ่ 1/3 เฟรม), ท่าหันหลัง `back`, นั่ง/คุดคู้, silhouette, เงาบนผนัง, ภาพผ่านกรอบ — ภาพกว้างที่ตัวละครยืนหน้าตรงเต็มตัวเก็บไว้เป็นข้อยกเว้น
- **มือใน insert มาจากฝั่งที่ตัวละครอยู่** ในช็อตข้างเคียง, แขนใน insert วาดใหญ่ (แขนเสื้อกว้าง 100–130 px) และสีเสื้อตาม `src/cast.json` (CLAUDE.md ข้อ 13)

## 6. อะไรคงที่ อะไรอิสระ

| คงที่ (ห้ามเปลี่ยน) | อิสระ (ผู้กำกับตัดสินเอง) |
|---|---|
| ตัวละครและชุดจาก `src/cast.json`, ความสูงสัมพัทธ์ | มุมกล้อง ขนาดภาพ จำนวนช็อตต่อสถานที่ |
| คนพูดเท่านั้นที่ขยับปาก | จะใช้ `Stage` หรือเขียนช็อตเป็น SVG/React เองทั้งหมด |
| deterministic (`rnd`, ไม่มี `Math.random`) | สร้างฉากใหม่ ห้องใหม่ VP ใหม่ ต่อสถานที่ |
| safe zone ของ caption/subtitle, ตัวหนังสือ ≥ 28 px | จัดองค์ประกอบ สมมาตรหรือไม่ ตัวละครอยู่ตรงไหน |

## 7. Storyboard ก่อน แล้วค่อยทำให้ขยับ

วาดให้ถูกที่ key frame (Board frame ที่ 60 % ของช็อต) ก่อน ยังไม่ต้องขยับ — `npm run check` แล้วเปิด `out/<slug>-board/` ทั้งชุด ถามทีละช็อต:

1. **อ่านออกในหนึ่งวินาที** ที่ขนาดมือถือ: subject และการกระทำชัด ถ้าต้องฟังเสียงถึงเข้าใจ → จัดเฟรมใหม่
2. **ภาพตรงกับ `note`** — ถ้า note บอก "แสงลอดใต้ประตู" ภาพต้องมีแสงลอดใต้ประตูให้เห็นชัด
3. **ขนาดเปลี่ยนทุกคัต**; ทั้งชุดมี wide, medium, close จริง (หัวครึ่งเฟรม), insert และมุมต่ำ/สูงอย่างน้อยหนึ่ง
4. **แสงมาจากของที่เห็น** subject อยู่ในหรือตัดกับแอ่งแสง โทนกลางมืด ไม่มีอะไรสว่างเท่ากันทั้งเฟรม
5. **ตัวละครเด้ง**: หน้าสว่าง/คมที่สุดในบริเวณ rim ฝั่งแสง ไม่มีแขนขาจมฉาก
6. **มีความลึก**: FG มืดเบลอราว 1/3 ของช็อต (ไม่ใช่ทุกช็อต — ใส่เมื่อมีเหตุผล: แอบมอง ข้ามไหล่ ถูกขัง), BG นุ่มใน close-up
7. **โลกเต็ม** ภาพกว้างไม่มีผนังโล่ง ไม่มีเฟอร์นิเจอร์ลอย
8. **perspective ถูก**: ของนั่งบนพื้นผิวของมัน ขนาดเข้ากับคน วิ่งเข้า VP เดียว
9. **การแสดงตรงประโยค**: สีหน้าและท่าบอกประโยคได้โดยไม่มีเสียง; คนพูดคนเดียวขยับปาก
10. **ต่อเนื่อง**: ชุด ผัง ห้อง ตำแหน่งของ เดิมทุกช็อตของสถานที่เดียวกัน
11. **contact sheet ทั้งเรื่องไม่ใช่ภาพเดียวซ้ำ** — หรี่ตาดู ถ้าแถวหนึ่งเหมือนกันหมด ให้ทำช็อตในแถวนั้นใหม่

ผ่านแล้วค่อย animate (push, กะพริบ, มือ, ฝุ่น) แล้วดู still เพิ่มตอนเริ่ม/จบช็อต

## 8. Audit เป็นเครื่องมือของผู้กำกับ ไม่ใช่เจ้านาย

- `npm run shots` (setup, ช็อตที่ไม่มี `note`, กรอบเดิมซ้ำ, scene ที่ถูกใช้มากสุด) และ `npm run look` (เงา ทิศแสง contrast) พิมพ์ ✗ เป็น **คำถาม**: เปิด frame นั้นดู แล้วแก้ หรือเขียนเหตุผลหนึ่งบรรทัดว่าทำไมภาพถูกแล้ว
- **ตัวเลขผ่านแต่ภาพแบน = ไม่ผ่าน; ตัวเลขไม่ผ่านแต่ภาพดีและมีเหตุผล = ผ่าน**
- ห้ามตั้งชื่อ `view` ให้ผ่าน audit (`-low` ที่ไม่ได้ต่ำจริง) — ชื่อ view ต้องบอกสิ่งที่ภาพเป็น

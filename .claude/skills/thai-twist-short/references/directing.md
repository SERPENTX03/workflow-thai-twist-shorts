## 0. ทำไมภาพของเราแข็ง (หลักฐาน)

`same-child` 400 ช็อต **ผ่านโควตาเก่าทุกข้อ** (`npm run shots` เคยขึ้น "all variety checks pass") แต่ contact sheet ยังดูเป็นภาพเดียวกันทั้งเรื่อง: ผนังไม้หน้าตรง ตัวละครยืนหน้าตรงเต็มตัว แสงสีน้ำตาลเท่ากันทั้งห้อง สาเหตุไม่ใช่ฝีมือวาด แต่เป็น **ระบบที่เราสั่งให้ทำ**:

| สาเหตุ | ในระบบเก่า | ผลบนจอ |
|---|---|---|
| 1. ช็อต = พารามิเตอร์ของ backdrop | 69 ช็อตใช้ scene `rumpai`, 60 ช็อตใช้ `mali`; ช็อตหนึ่ง = scene + `view` + `data.cam` + actor string | ทุกช็อตของห้องนั้นคือภาพเดียวกันที่ zoom/เลื่อน; `rumpai:tonroom` กรอบเดียวกัน 10 ครั้ง |
| 2. ฉากเป็นภาพด้านหน้า (elevation) | `Stage` = โลกด้านข้างที่มีเส้นพื้น `FLOOR` เส้นเดียว ผนังขนานกับจอ แล้วแปะ `PerspFloor`/`SideWall` ทับทีหลัง | กล้องเข้าไป "ในห้อง" ไม่ได้ ได้แค่ส่องโปสเตอร์ใกล้ขึ้น มุมต่ำ/สูงเป็นแค่ชื่อ |
| 3. "close" ไม่ใกล้จริง | auto-close ของ `Stage` และ S4 เดิม = z 1.75–1.9 | ได้ภาพครึ่งตัว (ซึ่ง what-if เรียกว่า medium) — ไม่มีหน้าเต็มจอ ไม่มี ECU ที่ตาหรือมือ |
| 4. กฎเป็นโควตาและคำต่อท้าย | `-low` `-fif` ต้องมีกี่ช็อต, EYE ≤ 40 %, FG 20–35 % ทุกช็อตระทึก, เงา ≥ 60 % | AI ตั้งชื่อ view ให้ผ่าน audit, แปะก้อนเบลอดำที่ขอบจอให้ครบ "FG" — ตัวเลขผ่าน ภาพไม่ดีขึ้น |
| 5. แสงเป็นเกรดทั้งเฟรม | `Grade night/dim/noir` หรี่ทั้งภาพ + `Glow` ใหญ่ | มืดเท่ากันทั้งห้อง ไม่มีแอ่งแสง ไม่มีมุมมืด แสงไม่ได้มาจากอะไร |
| 6. Gallery กลายเป็นเมนู | CLAUDE.md บอก "routine = gallery set + preset `-wide -med -ots -close`" และ "custom ได้เฉพาะช็อตระทึก" | ช็อตส่วนใหญ่ถูกบังคับเป็น backdrop สำเร็จรูป ความคิดของผู้กำกับเหลือแค่ช็อตไคลแมกซ์ |
| 7. ตัวละครยืนเต็มตัวเสมอ | "full figures ≥ 600 px", px-per-cm เดียวต่อช็อต, sprite หน้าตรง | หุ่นกระดาษกลางห้อง; การแสดงไม่มี เพราะไม่มีอะไรให้มือ/ตัวทำ |

what-if ไม่ได้มีกฎมากกว่าเรา (look.md 92 บรรทัด) — ต่างกันที่ **วาดทีละภาพ**: ทุกช็อตมีประโยคบอกภาพ (`note`), ทุกช็อตเป็นคอมโพเนนต์ของมันเอง, ฉากเป็นห้องสามมิติที่กล้องเข้าไปได้, แสงมาจากของที่เห็น แล้ว veil กดโทนกลางลง

## 1. ลำดับคิดของผู้กำกับ (ทำทีละช็อต)

1. **ประโยคนี้ทำให้คนดูรู้สึก/รู้อะไร** — ไม่ใช่ "ฉากนี้อยู่ห้องไหน"
2. **ภาพเดียวที่บอกสิ่งนั้นโดยไม่ต้องมีเสียง** — เขียนเป็น `note` หนึ่งประโยค: *ใคร ทำอะไร กับอะไร มองจากที่ไหน แสงมาจากไหน*
3. **ขนาดภาพและมุม** ตามสิ่งที่ภาพต้องโชว์ (ข้อ 2) — มือที่สั่น = insert, ความโดดเดี่ยว = กว้างมาก, ใครมีอำนาจ = มุม
4. **แสง** ที่ทำให้สิ่งนั้นเด่นที่สุดในเฟรม (ข้อ 4)
5. **สร้าง**: เลือกชิ้นจาก kit ที่ช่วย หรือเขียนเองทั้งช็อต — kit เป็นอะไหล่ ไม่ใช่แม่แบบ

ถ้าข้อ 2 เขียนไม่ออก ช็อตนั้นยังไม่พร้อมวาด — ห้ามแก้ด้วย "ยืนสองคน two-shot ไปก่อน"

ตัวอย่าง `note` ที่ดี (จาก dead-come-home): *"ประตูไม้จากด้านใน สั่นทุกครั้งที่เคาะ แสงเย็นลอดใต้ประตู มีเงาเท้าสองข้าง"* · *"มุมพื้น macro: ช่องใต้ประตู แสงเย็น เงาเท้าซีดขยับน้ำหนัก"* · *"ข้ามไหล่ที่มืดเบลอ มือเขาเอื้อมไปที่กลอน หยุด แล้วชักกลับ"*
ตัวอย่างที่ไม่ใช่ภาพ: *"ภาคคุยกับมะลิ"* · *"ห้องนอน กลางคืน"* · *"two-shot"*

## 2. Shot list = ลำดับภาพ ไม่ใช่ลำดับ preset

- ทุกช็อตกล้อง (ไม่ใช่การ์ด) มี `"note"` ใน story.json ก่อนวาดอะไร (`npm run shots` เตือนช็อตที่ขาด)
- **ลำดับของสถานที่หนึ่ง** (coverage): เปิดด้วยภาพที่บอกภูมิศาสตร์ (ใครอยู่ตรงไหน แสงอยู่ตรงไหน ทางเข้าอยู่ตรงไหน) แล้วค่อย **เข้าไปข้างใน**: medium → close → insert ของสิ่งที่ประโยคพูดถึง → ปฏิกิริยา ตัดกลับไปกว้างเมื่อสถานการณ์เปลี่ยน
- **ทุกคัตเปลี่ยนขนาดภาพหรือมุม** — เพื่อนบ้านสองช็อตห้ามขนาด+มุมเดียวกัน (กฎเดียวที่บังคับ เพราะมันคือ jump cut)
- **ไม่ต้องเห็นทุกคนทุกช็อต** บทสนทนาไม่จำเป็นต้องเป็น two-shot: คนพูด close, คนฟัง close, มือ, ของ, ข้ามไหล่ — คนดูต่อภาพเองได้
- **เสียงนำภาพได้**: ประโยคของคนที่ไม่อยู่ในเฟรม = ภาพของสิ่งที่เขาพูดถึง หรือหน้าคนฟัง (CLAUDE.md ข้อ 10: คนในเฟรมห้ามขยับปาก)
- ช็อตซ้ำกรอบเดิมใช้ได้ **เมื่อตั้งใจ**: เบาะแสกรอบเดิมทุกครั้ง, mirror framing ตอนเฉลย (`cinematography.md` A2, A5) — เขียนใน `note` ว่าซ้ำช็อตไหน

### ขนาดภาพ — วัดจากผลบนจอ ไม่ใช่จากชื่อ

| ขนาด | ผลบนจอ | 16:9 (คนสูง ~480 px ที่ z 1) | 9:16 |
|---|---|---|---|
| Establishing / wide | ห้องทั้งห้อง ตัวละครเล็ก ≤ 1/3 ความสูงเฟรม, เห็นแสงและทางเข้า | z 0.8–1.1 | ตัวละคร 400–700 px |
| Medium | เอวขึ้นไป | z 1.6–2 | หัว+ลำตัว เต็มความกว้าง |
| **Close** | **หัวสูงราว 40–55 % ของเฟรม** | **z 3–3.6** | หัว ≥ 600 px |
| Extreme close / ECU | ตา ปาก มือ เต็มเฟรม | z 4–5 | ตา/มือ ≥ 900 px |
| Macro insert | วัตถุ 40–60 % ของเฟรม, BG มืดหรือเบลอ | วาดใหญ่เอง ไม่ใช่ zoom sprite | วาดใหญ่เอง |

`Stage` จะ auto-close ที่ z 1.75 ถ้าไม่ใส่ `data.cam` — นั่นคือ medium ช็อตที่ตั้งใจให้เป็น close **ต้องตั้ง cam เอง**

## 3. ฉากคือสถานที่ที่กล้องเดินเข้าไป ไม่ใช่ฉากหลังที่ถ่ายหน้าตรง

- **สร้างแต่ละสถานที่ครั้งเดียว แล้วถ่ายหลายมุม** — ภายในใช้ room kit (`src/kit/room.tsx`, gallery `room-wide` / `room-close`):
  ```tsx
  const R = makeRoom({x: 700, y: 470}, {x0: 520, x1: 1500, y0: 220, y1: 760}, 3.4); // VP, กล่องผนังหลัง, ความลึก
  <RoomShell r={R} id="s12" />                                   // เพดาน ผนังข้าง พื้น ผนังหลัง ลายไม้วิ่งเข้า VP
  <RFace r={R} pts={[[0.62,0.2,0],[0.86,0.2,0],[0.86,0.55,0],[0.62,0.55,0]]} fill="#8fb0d8" />   // หน้าต่างบนผนังหลัง
  <RBox r={R} u={[0.04,0.4]} v={[0.82,1]} w={[0.12,0.6]} front="#4a3020" top="#d8d2c4" />        // เตียง (มีเงาสัมผัสให้)
  const s = standAt(R, 0.7, 0.45);                               // เท้าของคนที่ยืนที่ (u, w) → cast "who@x,y"
  roomPxPerCm(R, 0.45)                                           // px-per-cm ที่ระยะนั้น → คนไกลเล็ก คนใกล้ใหญ่ อัตโนมัติ
  <LightVeil id="s12" lights={[[x, y, r]]} o={0.45} />           // กดโทนกลาง เหลือแอ่งแสง
  ```
  แล้วแต่ละช็อตแค่ย้ายกล้อง (`data.cam` หรือ `camT`) — ห้อง หน้าต่าง แสง เฟอร์นิเจอร์ยังอยู่ที่เดิมและถูก perspective ทุกมุม
- **วาง VP ไม่ตรงกลาง** และเปลี่ยน VP ต่อสถานที่ได้ (มุมห้อง = VP ใกล้ขอบ); มุมต่ำ = `vp.y` ต่ำลงใกล้พื้น, มุมสูง = `vp.y` สูง เห็นพื้นมาก — ทำ view ใหม่ของห้องเดิมด้วย `makeRoom` อีกตัวที่ VP ต่าง ไม่ใช่แค่ zoom
- **โลกต้องเต็ม**: ภาพกว้างมี ≥ 15–20 ชิ้นที่ออกแบบ (ชั้นวาง ปฏิทิน พัดลม หม้อข้าว ผ้าขาวม้า ปลั๊กพ่วง ศาลพระภูมิ) ไม่มีผนังโล่ง ทุกอย่างที่ตั้งบนพื้นมีขาและเงาสัมผัส
- **ฉากเก่า (`WoodRoom`, `Classroom`, `ShopRow`…) ยังใช้ได้** เป็น establishing หรือฉากหลังเบลอของ close-up; ถ้าสถานที่หนึ่งต้องถ่ายเกิน ~6 ช็อต ให้สร้างใหม่เป็นห้องสามมิติ แล้วย้ายเข้า `src/kit/` (CLAUDE.md ข้อ 6)
- **Gallery คืออะไหล่และไม้บรรทัด** — คนยืนกลางการ์ดมีไว้เทียบขนาด ไม่ใช่องค์ประกอบภาพ ไม่มีช็อตไหนต้อง "หน้าตาเหมือนการ์ด gallery"

### 3.1 ขนาดจริงของของในฉาก (ใช้คำนวณ ไม่ใช่กะด้วยตา)

คนในเรื่องสูง 170 ซม. = 520 หน่วยของตัวละคร; ที่ 3 px/ซม. ผนังหลังห้อง `makeRoom` สูง ~280 ซม. ใช้ `roomPxPerCm(R, w)` แล้วคูณขนาดด้านล่าง ถ้าของชิ้นไหนดูผิดสัดส่วนกับคน ให้เช็กตารางนี้ก่อนแก้ภาพ

| ของ | สูง/ขนาด (ซม.) | หมายเหตุ |
|---|---|---|
| เก้าอี้นั่ง (ที่นั่ง) | สูง 45 · พนักสูงถึง ~90 | เก้าอี้สำนักงานล้อเลื่อน ที่นั่ง 48–52, พนัก ~100 |
| ม้านั่ง/ลังนั่ง | 40–45 | ม้านั่งโรงพยาบาลยาว 150–180 |
| โต๊ะทำงาน | 75 ลึก 60–70 | แล็ปท็อปปิดหนา 2 เปิดจอสูง 22 กว้าง 33 |
| โต๊ะกินข้าว/หน้าเขียง | 75–80 | เขียงหมูในเรื่องนี้เตี้ยพิเศษ 55–60 (ผู้นั่งรถเข็น) |
| เตียง/แท่นศพ | 50–60 | หนา 15–20 บนขา |
| ตู้ล็อกเกอร์/ตู้เหล็ก | 180–190 กว้าง 40 | ตู้เก็บเอกสารเตี้ย 90–120 |
| ชั้นหนังสือ | 180–200 | หนังสือหนึ่งเล่มสูง 22–28 |
| ประตู | 200 กว้าง 80–90 | ประตูตู้แช่/ประตูเหล็กต่ำ 120–140 ได้ถ้าเรื่องบอก |
| เสาน้ำเกลือ | 180–200 | |
| แก้ว/มัก | 9–10 | มือถือ 15×7 หนา 0.8 · กล่องโฟม 40×30×25 · พัด 30 |
| หน้าต่าง | ขอบล่างสูง 90–100 สูง 120–150 | |

กฎใช้: ของที่ตั้งพื้นให้ฐานอยู่ที่ `standAt(R, u, w)` เดียวกับเท้าคน ของที่คนถือต้องเล็กกว่ามือทั้งสองรวมกัน ถ้าต้องการให้ของ "ใหญ่เพื่ออ่านออก" (insert) ให้วาดเป็นช็อต insert ของตัวเอง ไม่ขยายกลางฉากกว้าง

## 4. แสงทำงานครึ่งหนึ่งของภาพ

- **แสงทุกดวงมาจากของที่เห็นได้**: หน้าต่างที่มีพระจันทร์/แดด, หลอดไฟห้อย, ตะเกียง, จอมือถือ, ทีวี, ประตูที่เปิดสู่ห้องสว่าง, เทียน, ไฟหน้ารถ
- **ผนังโทนกลางค่อนมืด** (ไม่ใช่น้ำตาลอ่อนสว่าง) เพื่อให้แสงอ่านออก แล้ว `LightVeil` กดโทนกลางลงอีก เหลือ **รู** ตรงที่แสงตก: รูขนาดเท่าแอ่งแสงจริง (รูเท่าผนังทั้งผนัง = แบนอีก) ค่า `o` ~0.3 สำหรับภาพกว้างที่ต้องเห็นพื้น, 0.4–0.55 ที่อื่น (Stage `Grade` ยังหรี่ทับอีกชั้น — ลด `o` ถ้าใช้เกรดกลางคืน)
- **ตัวละครเด่นที่สุดในบริเวณของเขา**: หน้าสว่าง/คมที่สุด, rim ฝั่งที่หันเข้าแสง, ไม่มีแขนขามืดจมผนังมืด; ของที่สว่างกว่าหน้า (ตู้เย็นขาว ผ้าปูที่นอนขาว) ลดลงหนึ่งขั้น
- **ฝุ่นในลำแสง หมอก bokeh** ทำให้มีชีวิตแม้ตัวละครนิ่ง
- **กลางวันก็ต้องมีทิศ**: สว่างได้ แต่แสงเข้ามาด้านเดียว มีด้านมืด มีเงา
- ความมืดตามอารมณ์ยังเป็นแนวทาง (`depth-light.md` §4) แต่ **ดูจากภาพ** — `npm run look` เป็นเครื่องวัดช่วยหา ไม่ใช่ข้อสอบ

## 5. การแสดงและการวางตัว (Staging)

- **ตัวละครทำอะไรกับอะไรเสมอ**: นั่งขอบเตียง กอดเข่าพิงผนัง ก้มเก็บของ ถือโทรศัพท์ส่องหน้า เปิดลิ้นชัก ยืนหันหลังมองประตู — ไม่ยืนแขนแนบตัวกลางห้อง
- **วางตามพื้นที่ของห้อง** (`standAt(R, u, w)`) ไม่ใช่ตามเส้นพื้นเส้นเดียว: คนหนึ่งใกล้กล้อง คนหนึ่งไกล = ความลึกและอำนาจ (`cinematography.md` A3)
- **ตัวละครแทบไม่ต้องขยับ** ชีวิตมาจากรอบตัว: หน้าเปลี่ยนตามจังหวะ (กะพริบตาตอนเปลี่ยนสีหน้า), มือเปลี่ยนท่า, push-in ช้า, ฝุ่น ไฟกะพริบ ผ้าม่านไหว
- **ตัวละครหัน 3/4 และแสดงด้วยแขนได้แล้ว** (pose rig, `cast-library.md` → Pose rig): `yaw=0.4` หันหาสิ่งที่มอง/คนที่คุยด้วย, `armR=reach` เอื้อมกลอนประตู, `armL=mouth` ปิดปากตอนตกใจ, `armR=hold prop=phone` ส่องโทรศัพท์, `head=-6` เอียงหัวฟัง, `look=0.6` เหลือบตา — ใส่ `>` ให้ขยับในช็อต (`yaw=0>0.5` หันมาช้าๆ ตอนได้ยินเสียง) และ `faces=worried@0,shock@40` ให้หน้าเปลี่ยนผ่านการกะพริบตรงจังหวะ ชุดจริงตาม `src/cast.json` ตามไปทุกท่า
  - **หันเข้าหากัน**: สองคนคุยกันให้ yaw หาอีกฝ่าย (ซ้าย `yaw=0.4` ขวา `yaw=-0.4`) ไม่ใช่ยืนหน้าตรงคู่กัน; คนที่ไม่สนใจ / ปิดบังให้หันออก
  - **แขนบอกการกระทำ ไม่ใช่ห้อยไว้**: ทุกช็อตที่ตัวละครยืน ถามว่ามือทำอะไร — ถือ เอื้อม ชี้ กอดอก ล้วงกระเป๋า เท้าเอว จับคาง; แขนพักทั้งสองข้างคือข้อยกเว้น
  - **ขีดจำกัดที่ยังเหลือ**: rig หมุนได้ราว ±0.6 (เกินนั้นหน้าหลุดหัว) และใช้กับท่า `stand` เท่านั้น — มุมด้านข้างเต็ม, ท่านั่ง/คุดคู้ที่ต้องแสดงมือ, และหัวที่วาดเอง (`elder`, `monk`, `novice`, `aunt-family-B` หันได้น้อย) ยังต้องกำกับด้วย close/ECU, insert มือ, ข้ามไหล่, `back`, silhouette, เงาบนผนัง, ภาพผ่านกรอบ — ภาพกว้างคนยืนหน้าตรงแขนห้อยเต็มตัวยังเป็นข้อยกเว้นเหมือนเดิม
- **หันให้เห็นจริง**: `yaw` ต่ำกว่า ~0.3 บนจอยังอ่านเป็นหน้าตรง (`fifth-room` ช็อต 126 ที่ `yaw=-0.35` หันแค่พอสังเกต) ใช้ 0.4–0.6 เมื่อต้องการให้คนดูเห็นว่าเขาหันหาอะไร และใส่ `look=` ไปทางเดียวกัน `npm run shots` นับคนที่ยืนหน้าตรงแขนห้อย (เกิน 10 % = ✗) และหน้าใน close ที่มองตรงออกมามือเปล่า (เกิน 30 % = ✗)
- **มือใน insert มาจากฝั่งที่ตัวละครอยู่** ในช็อตข้างเคียง, แขนใน insert วาดใหญ่ (แขนเสื้อกว้าง 100–130 px) และสีเสื้อตาม `src/cast.json` (CLAUDE.md ข้อ 13)

### 5.1 Close-up คือการแสดง ไม่ใช่รูปติดบัตร

ปัญหาที่เห็นใน `fifth-room` และ `father-ledger`: ช็อต close จำนวนมากคือหน้าตรง กลางจอ บนฉากเบลอ ต่างกันแค่สีหน้าและฉากหลัง เรียงกันแล้วเป็นรูปติดบัตรชุดเดียว (`father-ledger` ตัวละครในช็อต close หันแค่ 10 จาก 46) ก่อนรับช็อต close ให้ตอบสี่ข้อ:

1. **เขามองอะไร** หัวและตาหันไปหาสิ่งนั้น (`yaw` 0.4–0.6 + `look`) หน้าอยู่บนเส้น 1/3 ที่ว่างอยู่ฝั่งที่มอง ไม่ใช่กลางจอ
2. **มืออยู่ไหน** close ที่ดีมักมีมือในเฟรม: ปิดปาก จับคอเสื้อ ถือของแนบอก ยกโทรศัพท์ (`armL=mouth`, `armR=chest`, `arm=r-phone`)
3. **หน้าเปลี่ยนไหมในช็อต** `faces=worried@0,shock@40` ให้สีหน้าเปลี่ยนตรงคำที่กระทบ หน้าเดียวตลอดช็อตคือภาพนิ่ง
4. **อะไรอยู่หลังเขา** ฉากหลังของ close คือห้องเดิมจากมุมเดิม เบลอ และมีแหล่งแสงเดิมอยู่ในเฟรม ไม่ใช่สีพื้นหรือฉากเบลอที่บอกไม่ได้ว่าที่ไหน

ถ้าตอบไม่ได้สักข้อ ช็อตนั้นควรเป็น insert ของสิ่งที่ประโยคพูดถึง หรือหน้าของคนฟัง ไม่ใช่หน้าคนพูดอีกรอบ

### 5.2 สไตล์เดียวทั้งเฟรม

- **ECU ของหน้าใช้หน้าของ sprite** (ซูมที่ z 4–5) ไม่วาดตาหรือปากใหม่แบบสมจริง ตัวละครของเราตาเป็นจุด ปากเป็นเส้น ตาที่มีม่านตา ขนตา และริมฝีปากไล่เฉด (ECU ตาใน `fifth-room` ช็อต 7, ปากใน `father-ledger` ช็อต 144) เป็นคนละเรื่องกับหน้าที่คนดูเพิ่งเห็น ถ้าต้องวาดใหม่เพราะ sprite แตกเมื่อซูม ให้ใช้ภาษาเดียวกัน: รูปทรงเรียบ สีพื้น ตาจุดขยายใหญ่
- **มือใน insert** ใช้ `Hand` ของ kit (`src/kit/inserts.tsx`) สีผิวและแขนเสื้อจาก `src/cast.json` นิ้วทรงเดียวกับมือของ sprite ไม่วาดมือสัดส่วนสมจริงข้างตัวละครหัวโต
- **เส้นขอบ**: ตัวละครไม่มีเส้นขอบ เฟอร์นิเจอร์และของในฉากเดียวกันก็ไม่ควรมีเส้นดำหนา ให้แยกรูปทรงด้วยค่าสีและเงา
- **ขอบแสง (rim) อยู่ฝั่งแสงเท่านั้น** `rimFilter` ไม่เรืองรอบตัวแล้ว ถ้าตัวละครจมฉาก ให้แก้ที่แสง (แอ่งแสงหลังตัว, ผนังมืดลง) ไม่ใช่เพิ่มขอบเรือง
- **ภายนอกก็เป็นสถานที่**: บ้าน ตึก ถนน ไม่ถ่ายหน้าตรงขนานจอ (`fifth-room` ช็อต 49) ให้ถ่ายเฉียงจากหัวมุม มีพื้นหน้า รั้ว หรือเสาไฟที่วิ่งเข้าจุดลับตา และคนยืนหันหาสิ่งที่ทำ
- **เท้ากับแถบซับ**: ตัวละครเต็มตัวให้เท้าอยู่เหนือแถบซับ หรือครอปที่เอว/เข่าอย่างตั้งใจ ไม่ปล่อยให้ขาจางหายไปในเงาซับ

## 6. อะไรคงที่ อะไรอิสระ

| คงที่ (ห้ามเปลี่ยน) | อิสระ (ผู้กำกับตัดสินเอง) |
|---|---|
| ตัวละครและชุดจาก `src/cast.json`, ความสูงสัมพัทธ์ | มุมกล้อง ขนาดภาพ จำนวนช็อตต่อสถานที่ |
| คนพูดเท่านั้นที่ขยับปาก | จะใช้ `Stage` หรือเขียนช็อตเป็น SVG/React เองทั้งหมด |
| deterministic (`rnd`, ไม่มี `Math.random`) | สร้างฉากใหม่ ห้องใหม่ VP ใหม่ ต่อสถานที่ |
| safe zone ของ caption/subtitle, ตัวหนังสือ ≥ 28 px | จัดองค์ประกอบ สมมาตรหรือไม่ ตัวละครอยู่ตรงไหน |
| กฎมือ (`hands-poses.md`) | แสง สี เกรด ต่อช็อต |
| มอเตอร์ไซค์ใช้ `Motorcycle` + ท่าขี่ shot 021 (ตัวรถและท่าคนขี่) | มุมที่ถ่ายมอเตอร์ไซค์ (ต่ำ ข้ามไหล่ ไฟหน้า กระจกมองข้าง ล้อ) |
| ของที่ใช้ร่วมกันย้ายเข้า `src/` | การเลือกใช้ของใน gallery หรือไม่ใช้เลย |

**ทุกช็อตเป็นช็อตที่ออกแบบ** — ไม่มีชั้น "routine shot" ที่ทำแบบสำเร็จรูป ช็อตข้อมูลอาจเรียบง่ายกว่าช็อตระทึก แต่ยังต้องมีภาพที่คิดมาแล้วใน `note`

## 7. Storyboard ก่อน แล้วค่อยทำให้ขยับ

วาดให้ถูกที่ key frame (Board frame ที่ 60 % ของช็อต) ก่อน ยังไม่ต้องขยับ — `npm run check` แล้วเปิดเฟรมของ **ช็อตที่เพิ่งวาดหรือแก้** ที่ขนาดเต็ม ถามทีละช็อต (นี่คือการตรวจตอนวาด ทำไปทีละสถานที่; ตอน review ท้ายเรื่องเปิดเฉพาะช็อตที่ audit ชี้และช็อตที่เปลี่ยน ตามกฎ 5):

1. **อ่านออกในหนึ่งวินาที** ที่ขนาดมือถือ: subject และการกระทำชัด ถ้าต้องฟังเสียงถึงเข้าใจ → จัดเฟรมใหม่
2. **ภาพตรงกับ `note`** — ถ้า note บอก "แสงลอดใต้ประตู" ภาพต้องมีแสงลอดใต้ประตูให้เห็นชัด
3. **ขนาดเปลี่ยนทุกคัต**; ทั้งชุดมี wide, medium, close จริง (หัวครึ่งเฟรม), insert และมุมต่ำ/สูงอย่างน้อยหนึ่ง
4. **แสงมาจากของที่เห็น** subject อยู่ในหรือตัดกับแอ่งแสง โทนกลางมืด ไม่มีอะไรสว่างเท่ากันทั้งเฟรม
5. **ตัวละครเด้ง**: หน้าสว่าง/คมที่สุดในบริเวณ rim ฝั่งแสง ไม่มีแขนขาจมฉาก
6. **มีความลึก**: FG มืดเบลอราว 1/3 ของช็อต (ไม่ใช่ทุกช็อต — ใส่เมื่อมีเหตุผล: แอบมอง ข้ามไหล่ ถูกขัง), BG นุ่มใน close-up
7. **โลกเต็ม** ภาพกว้างไม่มีผนังโล่ง ไม่มีเฟอร์นิเจอร์ลอย
8. **perspective ถูก**: ของนั่งบนพื้นผิวของมัน ขนาดเข้ากับคน วิ่งเข้า VP เดียว
9. **การแสดงตรงประโยค**: สีหน้าและท่าบอกประโยคได้โดยไม่มีเสียง; คนพูดคนเดียวขยับปาก
10. **ต่อเนื่อง**: ชุด ผัง ห้อง ตำแหน่งของ เดิมทุกช็อตของสถานที่เดียวกัน
11. **contact sheet ทั้งเรื่องไม่ใช่ภาพเดียวซ้ำ** — หรี่ตาดู ถ้าแถวหนึ่งเหมือนกันหมด ให้ทำช็อตในแถวนั้นใหม่

ผ่านแล้วค่อย animate (push, กะพริบ, มือ, ฝุ่น) แล้วดู still เพิ่มตอนเริ่ม/จบช็อต

### 7.1 ปิดเสียงแล้วบอกได้ไหมว่าเห็นอะไร

บทเรียนจาก `rear-cam` ช็อต 0, 1, 5, 11: ผ่าน audit และวาดตรงชื่อ view ทั้งหมด แต่คนดูบอกไม่ได้ว่าภาพสื่ออะไร ก่อนรับเฟรม ให้ตอบคำถามพวกนี้จากภาพจริง ไม่ใช่จากโค้ดหรือ `note`:

1. **ปิดซับ เหลือขนาดมือถือ แล้วตั้งชื่อภาพได้ไหม** ต้องบอกเป็นคำนามที่เห็นได้: "ไรเดอร์คนเดียวบนถนนกลางหลุมศพ" ได้ / "แสงในหมอก" ไม่ได้ ถ้าซับต้องแบกความหมายทั้งหมด ภาพนั้นยังไม่เสร็จ
2. **ของทุกชิ้นใน `note` อยู่ในเฟรมจริงไหม** `note` เขียนว่า "ไฟหน้ามอเตอร์ไซค์" ต้องเห็นมอเตอร์ไซค์ ไม่ใช่เห็นแค่แสงของมัน ไล่เช็กทีละคำนาม
3. **แสงต้องมีเจ้าของ** ลำแสงลอยเปล่าอ่านไม่ออก (จุดกลมกับสามเหลี่ยมดูเหมือนดวงจันทร์) ต้องเห็นของที่ปล่อยแสงและสิ่งที่แสงตกลงไป ลำแสงมีทิศไปหาของที่เรื่องพูดถึง ขอบฟุ้ง ไม่เป็นสามเหลี่ยมขอบตัด ของที่จะเป็นเงาดำต้องวาด **ทับ** แสง ไม่ใช่อยู่ใต้แสง กล้องไม่ปล่อยแสง อย่าให้ทิศที่กล้องมองดูเหมือนไฟฉาย
4. **ของมืดใหญ่หน้ากล้องต้องมีเหตุ** ถ้ากินเกินราวหนึ่งในสี่ของเฟรม ต้องเป็น subject ที่เห็นรายละเอียดชัด (ยาง ซี่ล้อ โช้ก) หรือเป็นขอบเบลอที่ไม่บังเรื่อง แผ่นมืดที่บอกไม่ได้ว่าคืออะไรไม่ใช่ foreground ใบไม้และกิ่งไม้ให้วาดเป็นชิ้นเล็กตามกิ่ง ไม่ใช่ก้อนกลมซ้อนกัน
5. **ซิลูเอตต์ต้องมีฉากหลังสว่าง** ของดำบนฟ้าดำมองไม่เห็น และต้องเห็นรูปทรงเต็มพอจะเดาได้ ซุ้มประตูต้องเห็นโค้งบนกับเสาสองข้าง ไม่ใช่แท่งดำสองแท่ง
6. **เลือกมุมที่ sprite ไปด้วยได้** มอเตอร์ไซค์และตัวละครเป็นภาพด้านข้าง/หน้าตรง ถ้าวางบนถนนที่พุ่งเข้าจุดลับตาจะดูผิด ให้ถนนตัดเฉียงผ่านเฟรมแทน มุมสูงต้องให้หัวติดไหล่ อย่าให้ของในฉากบังตัวจนเหลือหัวลอย
7. **แถบซับ (ราว y ≥ 850 ใน 16:9) ไม่ใช่ที่วางเรื่อง** ของสำคัญอย่าไปอยู่ตรงนั้น และอย่าให้ของขาวหรือเส้นสว่างอยู่หลังตัวหนังสือ ถ้าเลี่ยงไม่ได้ให้ไล่เงาใต้ซับ
8. **ดูขนาดเต็มด้วย ไม่ใช่แค่ contact sheet** ช็อตที่ต้องเปิดเต็มทุกครั้ง: 3 ช็อตแรก ช็อตปิด cold open ช็อตเปิดบท ภาพเฉลย และช็อตที่ `note` พูดถึงของชิ้นเล็ก

9. **ของที่ตัวละครถือหรือใส่ต้องติดกับตัว** แว่นต้องอยู่บนตา (ใช้ `acc=glasses` ของ sprite ซึ่งตรงตาทุกท่า อย่าวาดทับเอง) ของที่ถือต้องอยู่ในมือจริงของตัวละคร **นับมือทุกเฟรม: คนหนึ่งมีสองแขนสองมือ** อย่าวาดแขนหรือ `<Hand>` เพิ่มข้างตัวละคร เพราะ sprite มีแขนอยู่แล้ว ให้ขยับแขนเดิมแทน (`arm=r-phone`, `armR=…`) ระบบจะเอาแขนที่พักอยู่ออกให้ ถ้าไม่มีท่าที่ต้องการ ให้เพิ่มท่าใน `src/cast/source/cast.svg` (`hands-poses.md`) `<Hand>` ใช้กับ insert ที่ไม่มีตัวละครในเฟรม
10. **ถ้าภาพดูแปลก ให้เปลี่ยนกล้อง ไม่ใช่ซ่อมรูปทรง** ตัวละครที่ประกอบจากวงกลมกับกรวย (มุมสูงเห็นแต่หัวกับเสื้อคลุมตัดครึ่ง) อ่านเป็นแท่งดำ ถ้า sprite ไปกับมุมนั้นไม่ได้ ให้ถอยเป็นภาพกว้างที่ระดับสายตาด้วยตัวละครจริงแล้วใช้ท่าทาง (yaw, arm) กับแสงเล่าเรื่อง `rear-cam` ช็อต 345 ทำแบบมุมสูงแล้วดูไม่เหมือนคน พอเปลี่ยนเป็นภาพกว้างที่ศาลา ธีร์ยืนกุมข้อมือพี่ชาติที่ใส่กุญแจมือ ก็อ่านออกทันที

**ช็อตเปิด:** 3 ช็อตแรกต้องเห็น *ใคร / ที่ไหน / อันตรายอะไร* รวมกันครบ และเฟรมแรกต้องมีจุดสว่างจุดเดียวที่สายตาไปหาทันที เรื่องมืดได้ แต่ภาพต้องอ่านออก มืดคือสิ่งที่อยู่รอบ subject ไม่ใช่ตัว subject

**ช็อต mirror:** สร้างจากคอมโพเนนต์เดียวกับต้นฉบับแล้วเปลี่ยนแค่แสงและสิ่งที่เปลี่ยนไป แก้ต้นฉบับเมื่อไรให้เปิดดูช็อต mirror ด้วย

**เรื่องเทคนิค:** `Motorcycle` มี `zIndex: 14` ของที่ต้องอยู่หน้ารถ (แสงแฉก ดอกยาง กรวด) ต้องตั้ง `zIndex` สูงกว่านี้ ไม่งั้นจะถูกรถทับโดยไม่มี error

## 8. Audit เป็นเครื่องมือของผู้กำกับ ไม่ใช่เจ้านาย

- `npm run shots` (setup, ช็อตที่ไม่มี `note`, กรอบเดิมซ้ำ, scene ที่ถูกใช้มากสุด) และ `npm run look` (เงา ทิศแสง contrast) พิมพ์ ✗ เป็น **คำถาม**: เปิด frame นั้นดู แล้วแก้ หรือเขียนเหตุผลหนึ่งบรรทัดว่าทำไมภาพถูกแล้ว
- **ตัวเลขผ่านแต่ภาพแบน = ไม่ผ่าน; ตัวเลขไม่ผ่านแต่ภาพดีและมีเหตุผล = ผ่าน**
- ห้ามตั้งชื่อ `view` ให้ผ่าน audit (`-low` ที่ไม่ได้ต่ำจริง) — ชื่อ view ต้องบอกสิ่งที่ภาพเป็น
- **เหตุผลที่ใช้ตอบ ✗ ต้องบอกว่าเห็นอะไรในเฟรม** "มืดตามเรื่อง" หรือ "ตั้งใจให้มืด" อย่างเดียวไม่นับ ต้องบอกว่า subject คืออะไรและอ่านออกจากอะไร ถ้าบอกไม่ได้ให้แก้ภาพ ช็อตเปิดมีธงเพิ่ม (`opening shot: contrast < 80`) ใช้กติกาเดียวกัน

## 9. เช็กลิสต์ "ปัญหาที่เจอซ้ำ" (ตรวจเองจากภาพก่อนส่งให้คนดู)

ไล่ตอนเปิด Board frame ของช็อตที่เพิ่งวาด ทุกข้อคือสิ่งที่ผู้ใช้ต้องแก้ให้ในเรื่อง `father-ledger` (พ.ย. 2026) เพราะผมวาดพลาดซ้ำ

1. **ของที่ถือ/ใส่ อยู่ในมือหรือบนตัวจริงไหม** ใช้ `prop=` กับท่าแขนของตัวละคร (พัด `prop=fan`, มือถือแนบหู `arm=r-phone prop=phone-ear`, แก้ว `prop=mug`) ไม่วาดลอยข้างตัว ไม่วาด `<Hand>` เพิ่ม
2. **ใครนั่ง มีที่นั่งไหม** (กฎข้อ 16) เก้าอี้/ม้านั่ง/ลังต้องอยู่ใต้สะโพก สูงตามตาราง §3.1; นั่งพื้นใช้ `crouch`
3. **ภาพกว้างคนอยู่กลางจอบนแกนสมมาตรไหม** ย้ายคนหรือกล้องไปเส้น 1/3 (ภาพกว้างที่ตั้งใจจัดกลางต้องบอกเหตุใน `note`)
4. **ตัวหนังสือหรือของสำคัญชนแถบซับไหม** (y ≥ ~850 ใน 16:9) ภาพเอกสาร/จอที่เต็มเฟรมให้จัดแถวไม่เกิน ~4 แถวและเว้นขอบล่าง
5. **ภาพ macro มีสองหน้าไหม** (split, สมุดคู่กัน) ต้องมีหัวบอกว่าฝั่งไหนคืออะไร
6. **ห้องเล่าเรื่องคนอยู่ไหม** อย่างน้อย 2 ชิ้นที่บอกอาชีพ, 2 ชิ้นบอกเวลา, 2 ชิ้นบอกอารมณ์ของเขา ห้องกล่องว่างไม่ผ่าน
7. **กล้องเคลื่อนจริงไหม** push 3–5% แทบมองไม่เห็นบนจอ ช็อตที่ต้องการแรงกดดันใช้ 8–15% (`cinematography.md` การเคลื่อนไหวกล้อง) `npm run shots` เตือนอัตโนมัติเมื่อช็อตยาวส่วนใหญ่ขยับน้อย; ช็อตที่ประกาศ `data.motion` (walk/pan/push/fx) ตรวจด้วย `npm run motion -- episodes/<slug>` ได้ภาพ 4 ช่วงต่อช็อต (`out/<slug>-motion.html`) ไม่ต้องเรนเดอร์วิดีโอ
8. **ของที่ใช้ซ้ำอยู่ใน `src/kit/props.tsx` หรือ gallery หรือยัง** ค้นก่อนวาดใหม่ ของที่เรื่องที่สองจะใช้ (เก้าอี้ เสาน้ำเกลือ พัด มือถือ แก้ว) ให้ย้ายเข้า kit ทันที (กฎข้อ 6)

# Cinematography — คู่มือกำกับภาพ Thai Thriller / Mystery / Twist (2D flat vector)

ใช้กับทั้ง Shorts (9:16, `thai-twist-short`) และเรื่องยาว (16:9, `thai-long-story`) อ่านไฟล์นี้ **ตอนวาง shot list ใน story.json (step 2)** และ **ตอนวาดฉาก (step 4)** — ก่อนเลือก `view`, `data.cam`, `data.light`, `data.cast` ของทุกช็อต

`art-direction.md` บอกว่าภาพ "หน้าตา" เป็นอย่างไร (palette, type, safe zone); ไฟล์นี้บอกว่า **กล้องอยู่ที่ไหนและทำไม** ถ้าขัดกัน: safe zone, กฎมือ (`hands-poses.md`) และ CLAUDE.md ชนะเสมอ

## 0. ปัญหาที่ไฟล์นี้แก้

AI มักจัดทุกช็อตเป็น **มุมข้างระดับสายตา (flat side-view) ระยะกลางค่อนกว้าง** เพราะ stage ของเราเป็นโลกด้านข้างที่มีเส้นพื้น `FLOOR` เดียว หลักฐานจาก `ghost-money` (112 ช็อต): preset ของศาลาทั้ง 5 ตัว (`wide` `desk` `row` `behind` `exit`) คือ z 1.0–1.2 ที่ cy 540–600 — **มุมเดียวกันหมด** แค่เลื่อนซ้ายขวา; `sala:row` ใช้ซ้ำ 17 ช็อต ภาพจึงไม่บอกว่าใครมีอำนาจ ใครถูกจับตา หรือเมื่อไหร่ความจริงเปลี่ยน

หลักข้อเดียวของไฟล์นี้: **กล้องอยู่นิ่งเมื่อเล่าข้อมูล และเปลี่ยนเมื่อความจริง อำนาจ หรือความปลอดภัยเปลี่ยน**

## 1. ภาษาของ setup — ตั้งชื่อ `view` ให้บอกมุมกล้อง

ทุกช็อตมี **setup** = ขนาดภาพ × มุมกล้อง × อุปกรณ์ภาพ (device) บอก setup ผ่าน **คำต่อท้ายของ `view`** (คั่นด้วย `-`) เพื่อให้คนอ่าน story.json และ `npm run shots` เห็นมุมกล้องโดยไม่ต้องเปิดโค้ด

| กลุ่ม | คำต่อท้าย | ความหมาย |
|---|---|---|
| **EYE** (flat, baseline) | *(ไม่มี)*, `-wide`, `-med`, `-ew` | ระดับสายตา มุมข้าง กว้าง/กลาง/กว้างมาก — ช็อต "ข้อมูล" |
| **CLOSE** | `-close`, `-ecu`, `-ins` · หรือ scene แบบ insert (`hand`, `insert…`, `phone`, `photo`, `page`, `clock`) | หน้าใกล้, ตา/ปาก/มือใกล้มาก, วัตถุเต็มจอ |
| **ANGLE** | `-low`, `-high`, `-top`, `-dutch` | มุมช้อน, มุมกด, มุมตรงลงจากบน, กล้องเอียง |
| **DEVICE** | `-ots`, `-pov`, `-fif`, `-sil`, `-split`, `-mirror`, `-cctv`, `-snap` | ข้ามไหล่, มุมมองตัวละคร, กรอบในกรอบ, เงาดำย้อนแสง, แบ่งจอ, เงาสะท้อน, กล้องวงจรปิด/ภาพบันทึก, snap zoom |
| **CARD** | scene `rule(s)` `title` `diagram` `news` `map` `next` `card` | การ์ด/กราฟิก/แผนที่ — นับแยก ไม่นับเป็นมุมกล้อง |

- รวมได้: `door-low-sil`, `mek-ots`, `car-mirror-pov` กลุ่มที่นับคือกลุ่มที่สูงสุด: DEVICE > ANGLE > CLOSE > EYE
- `-close` ที่ **ท้ายสุด** ทำให้ `Stage` auto-frame ผู้พูดเมื่อไม่มี `data.cam` และ `npm run story` เช็กว่ามี cam ถ้าเป็นทั้ง close และ low ให้ตั้งชื่อตามมุม (`tham-low`) แล้วใส่ preset เอง — มุมคือข้อมูลที่สำคัญกว่า
- `data.past: true` (ย้อนอดีต) เป็นเกรด ไม่ใช่ setup: ช็อตย้อนอดีตยังต้องมีคำต่อท้ายของมันเอง
- view ที่ไม่มีคำต่อท้าย = **ถือว่าเป็น EYE** ในการนับ ตั้งชื่อให้ถูกแทนที่จะหวังว่าจะถูกนับเป็นอย่างอื่น

## 2. Signature setups — 18 ท่ากล้องประจำโปรเจกต์และวิธีทำใน 2D

ค่า `data.cam` = `[z0, z1, cx, cy, cx1?, cy1?]` บนโลก landscape 1920×1080, `FLOOR` 930 ตัวเลขทั้งหมดเป็น **จุดเริ่ม** — เปิด Board frame ดูทุกครั้ง (CLAUDE.md ข้อ 3) แล้วเก็บค่าที่ใช้ได้เป็น preset ของฉากนั้น

สูตรช่วยคิด: กล้องที่ zoom `z` เห็นโลกสูง `1080 / z` px; ถ้าอยากให้เส้นพื้นอยู่ที่ขอบล่างของเฟรมพอดี `cy ≈ FLOOR − 510 / z`

| # | Setup | ใช้เมื่อ | ทำใน 2D flat อย่างไร |
|---|---|---|---|
| S1 | **Isolation wide** (`-ew`/`-high`) | เปิดฉาก, ตัวละครโดดเดี่ยว, หลังเหตุร้าย | ตัวละครสูง ≤ 25 % ของเฟรม อยู่ในสามส่วนล่าง พื้นที่ว่าง (negative space) ≥ 60 % ฝั่งที่ "ภัยจะมา"; pull-out `z` 1.1 → 1.0 |
| S2 | **Eye-level two-shot** (EYE) | ข้อมูล, บทสนทนาปกติ, กติกา | baseline ของ stage — **ใช้ได้แต่จำกัดโควตา** (ข้อ 6) |
| S3 | **Over-the-shoulder** (`-ots`) | บทสนทนาที่มีแรงกดดัน, การซักถาม | ผู้ฟังเป็น FG ขนาดใหญ่ (h ≈ 1.6–2× ปกติ) ตัดขอบเฟรม เห็นแค่หัว-ไหล่ เบลอ `blur(6px)` + มืดลง 40 %; ผู้พูดเป็น MG คม; ผู้ฟังห้าม `talk` (ข้อ 10 CLAUDE.md) |
| S4 | **Face close / ECU** (`-close`/`-ecu`) | ปฏิกิริยา, การโกหก, ความกลัว | close: z 1.75–1.9 ที่หัว; ECU: z 3–4 ที่ตาหรือปาก (ใบหน้าใหญ่ ≥ 500 px) จัดหน้าไว้ off-centre 1/3 ให้ฝั่งที่มองเป็นที่ว่าง |
| S5 | **Macro insert** (`-ins`/scene `hand`) | เบาะแส, วัตถุพยาน | `Plate` + `Hand` (`inserts.tsx`) วัตถุเต็ม 40–60 % ของเฟรม, BG มืดเกือบดำ, แสงจุดเดียวบนวัตถุ, push ช้า `z` [1, 1.08]; วงแดงประ (`backOut`) เฉพาะช็อตที่ "ชี้" |
| S6 | **Worm's eye / low power** (`-low`) | ตัวร้ายเผยตัว, ผู้มีอำนาจ, การข่มขู่ | ตัวละครเต็ม 85–100 % ความสูงเฟรม (`z ≈ 0.9 × 1080 / bodyH`, `cy ≈ FLOOR − 510/z`); หัวชนขอบบน มีเพดาน/หลอดไฟ/กิ่งไม้อยู่เหนือหัว; FG ที่ขอบล่างเป็นของใหญ่เบลอ (ขอบโต๊ะ, รองเท้า, หญ้า); แสงจากด้านล่าง (`Glow` ใต้คาง) เพื่อความน่ากลัว; ทางเลือก: keystone `perspective(1400px) rotateX(8–12deg)` origin ล่าง บนเลเยอร์ตัวละคร |
| S7 | **High angle** (`-high`) | เหยื่อ, ความอ่อนแอ, ถูกต้อนจนมุม, ความผิด | ตัวละคร ≤ 30 % ของเฟรม อยู่ล่าง ที่ว่างเหนือหัวมาก; ใน set ด้านข้าง ให้วาดเป็น view ของตัวเอง (พื้นเป็นสี่เหลี่ยมคางหมูกว้าง, เงาตกยาว) ดีกว่าแค่ zoom out; keystone กลับด้าน `rotateX(-8deg)` origin บน |
| S8 | **Top-down** (`-top`) | โต๊ะหลักฐาน, ศพ/โครงร่าง, แผนที่ใครอยู่ไหน | **ทำกับวัตถุ ไม่ใช่คน** (cast ไม่มีท่ามองจากบน): โต๊ะ + `Page`/`Ink` + `Hand` วางเป็นแผนผัง, หรือ `map` scene; สำหรับคนให้ใช้โครงร่างชอล์ก/ผ้าคลุม |
| S9 | **Dutch tilt** (`-dutch`) | ความระแวง, หลังรู้ว่ามีคนโกหก, โลกเริ่มผิด | `"data": {"tilt": -6}` บนช็อตที่ใช้ `Stage` (หรือ `[0, -7]` = ค่อยๆ เอียงตลอดช็อต); scene ที่ไม่ใช้ Stage: `<Tilt deg W H>` (`stage.tsx`, scale ปิดมุมให้เอง) — 5–8°, เอียงทางเดียวตลอดฉาก; การ์ด/HUD/`over` ไม่เอียง |
| S10 | **Silhouette / backlit door** (`-sil`) | คนยืนที่ประตู, ตัวตนที่ยังไม่เปิดเผย, ผี | roster `sil: true` หรือ `<Sprite silhouette>`; ประตู/หน้าต่างสว่าง (`Glow` + rect สีอ่อน) อยู่ **หลัง** ตัวละคร, ห้องด้านหน้ามืด (`Grade dim`/`dark`); ขอบตัว `rim=red` สำหรับตัวร้าย; เงาบนผนังที่มาถึงก่อนตัว = silhouette เฉือน (skew) บนผนัง |
| S11 | **Chiaroscuro pool** (EYE/`-close` + light) | สารภาพ, ซักถาม, อยู่คนเดียวกลางดึก | แสงแหล่งเดียว: `Bulb` + `Cone` (`light.tsx`) หรือ `LightMask` (`horror.tsx`) — ~60 % ของเฟรมเป็นเงา, ส่วนสว่างถือหน้าหรือเบาะแสเท่านั้น; `Grade dark` + `CornerShade` |
| S12 | **Frame-in-frame / voyeur** (`-fif`) | มีคนแอบดู, ถูกขัง, ความลับ | FG เป็นกรอบที่มืดและเบลอ (วงกบประตู, มุ้ง, ช่องบานเกล็ด, ใต้ถุนบ้าน, ซี่ลูกกรง, ใบไม้, ม่าน) กินขอบเฟรม 30–50 %; ตัวละครเล็กใน MG ไม่รู้ตัว; push ช้ามาก = "มีคนกำลังเข้าใกล้" |
| S13 | **POV mask** (`-pov`) | ตัวละครมองผ่านอะไรบางอย่าง | `<Pov kind W H f>{view}</Pov>` (`src/kit/pov.tsx`): `peephole` ตาแมว เลนส์โป่ง · `keyhole` รูกุญแจ · `crack` ประตูแง้ม (`open` 0–1 animate ได้) · `binoculars` · `blinds` บานเกล็ด (`sway={0}`) · `phone` กล้องมือถือ REC (`rec="00:01:42"`); `sway` (px) = มือ/ตาคนถือ, 0 = กล้องซ่อน; กระจกหน้ารถยังวาดเอง (+ `RainStreaks`); ช็อต POV ต้องมีช็อตคนมองก่อนหรือหลัง |
| S14 | **Split screen** (`-split`) | โทรศัพท์สองฝั่ง, สองที่ในเวลาเดียวกัน | `<Split W H a={…} b={…} angle={8} />` — 16:9 ซ้าย/ขวา, 9:16 บน/ล่าง (เลือกเองจาก W/H); แต่ละช่องวาดเหมือนช็อตเต็มที่จัดกลางไว้ที่ตัวละคร (`center` เลื่อนให้อยู่กลางครึ่งของมัน); `at` เลื่อนเส้นแบ่ง → ช่องของคนพูดกว้างกว่า; ปิด split ด้วย cut ไปช่องเดียวเมื่อบทสนทนาพลิก |
| S15 | **Mirror / reflection** (`-mirror`) | ตัวตนซ้อน, ผีอยู่ข้างหลัง, กระจกมองหลัง | `<MirrorFrame x y w h W H ox oy>{view}</MirrorFrame>` — กลับด้าน ซีด เบลอเล็กน้อย มีแสงสะท้อนกระจก; `ox, oy` = จุดของ view ที่อยู่กลางกระจก; สิ่งที่ต่างจากห้องจริง (ไม่มีใบหน้า, มีคนเพิ่มหนึ่งคน) คือเบาะแส; น้ำในคลอง (`Canal`) = กระจกตามธรรมชาติแบบไทย |
| S16 | **CCTV / recorded** (`-cctv`) | หลักฐานวิดีโอ, กล้องหน้ารถ, คลิปไลฟ์ | `<Cctv W H f cam="CAM 03" time="02:14:07" date? tint="grey"|"green" glitch>{view(cctvFrame(f))}</Cctv>` — ขาวดำ contrast สูง, scanline, grain, fisheye, REC กะพริบ, เวลาเดินเอง; `cctvFrame(f)` ให้ view ข้างในกระตุก 10 fps; วาง view ในมุมสูงจากมุมห้อง; เวลาในจอต้องตรงกับ HUD/continuity |
| S17 | **Snap zoom / crash push** (`-snap`) | วินาทีที่ความจริงเปิด, ตกใจ | `kf(f, [[0,1],[6,1.6]])` ภายใน 6–8 เฟรม + `shake` สั้น + cue `hit`/`bighit` บน beat 0; **ระดับ 3 — ใช้น้อยมาก** (ข้อ 4.3) |
| S18 | **Tracking pan + parallax** (EYE/`-wide` + move) | เดินทาง, ไล่ล่า, ค้นหา | pan `cx → cx1`; FG เลื่อนเร็วกว่า world 1.3–1.6×, BG ช้ากว่า 0.5–0.7× (ข้อ 5); ไล่ล่าใส่ `shake` 3–6 px และ FG วิ่งผ่านเฟรม (เสาไฟ `PowerPole`, ต้นไม้) |

### การเคลื่อนกล้อง = ความหมาย

| การเคลื่อน | ค่า | หมายถึง |
|---|---|---|
| push-in ช้า | z +4–8 % ทั้งช็อต (default) | ปกติ, กำลังจดจ่อ |
| push-in ชัด | z +15–25 % | การตระหนักรู้, ความกดดันเพิ่ม |
| pull-out | z ลดลง 8–15 % | โดดเดี่ยว, ผลที่ตามมา, "ภาพรวมเพิ่งปรากฏ" |

| snap | S17 | ช็อก |

## 3. Recurring archetypes — ฉากที่ต้องเจอซ้ำ และ Signature look ของแต่ละฉาก

แต่ละฉากมี **ลำดับช็อตต้นแบบ** (shot pattern) ใช้เป็นจุดเริ่ม ไม่ต้องใช้ครบทุกช็อต แต่ห้ามลดเหลือ EYE อย่างเดียว

### A1 · โทรศัพท์ / สายเบาะแสกลางดึก
*งาน:* เสียงจากที่ที่มองไม่เห็น = ภัยที่จับต้องไม่ได้
- **Pattern:** `-ins` จอมือถือสั่นบนโต๊ะมืด ("ไม่ทราบหมายเลข 02:13") → `-close` หน้าคนรับ แสงจอจากด้านล่าง (`Glow` สีฟ้าเย็น `170,200,255` a≈0.35 ใต้คาง) → `-fif`/`-ew` ห้องทั้งห้องมืด คนรับเล็กในแสงจอ ประตูหลังเขาแง้ม → (ถ้าเห็นปลายสาย) `-split` หรือปลายสายเป็น `-sil` ไม่เห็นหน้า → `-ecu` ตา/ปากตอนได้ยินประโยคสำคัญ
- ปลายสายพูด = `fx: "phone"`, คนถือโทรศัพท์ **ไม่ขยับปาก** ใบหน้า `worried`/`shock` (CLAUDE.md ข้อ 10)
- ห้าม: ช็อตคนยืนถือโทรศัพท์มุมข้างกลางห้องสว่างซ้ำ 3 ช็อต

### A2 · ตรวจเบาะแส / วัตถุพยาน
*งาน:* บอกคนดูว่า "จำสิ่งนี้ไว้" โดยไม่บอกว่าทำไม
- **Pattern:** `-med` ตัวละครก้มดู (เห็นว่าใครพบ) → `-ins` macro: มือ + วัตถุ, แสงจุดเดียว, BG ดำ → `-top` วัตถุบนโต๊ะเรียงเป็นแผนผัง (ถ้ามีหลายชิ้น) → `-ecu` จุดผิดปกติจุดเดียว (วันที่, รอยนิ้ว, เส้นด้าย) + rack focus → `-close` ปฏิกิริยา
- **Rack focus:** `<Far blur={kf(f,[[0,0],[16,8]])}>` บนสิ่งที่หลุดโฟกัส และ blur กลับด้านบนสิ่งที่เข้าโฟกัส — ย้ายความสนใจจากมือไปที่วัตถุโดยไม่ต้อง cut
- เบาะแสชิ้นเดิม **กรอบเดิม ด้านเดิม มือเดิม** ทุกครั้ง (`hands-poses.md`) เพื่อให้ตอนเฉลยจำได้ทันที
- ห้าม: วัตถุพยานเล็กกว่า ~120 px ในช็อตกว้างโดยไม่มี insert

### A3 · เผชิญหน้า / คุกคาม / ตัวร้ายเผยตัว
*งาน:* อำนาจเปลี่ยนมือ — ภาพต้องเห็นว่าใครอยู่สูงกว่า
- **Pattern:** `-sil` ตัวร้ายที่ประตูย้อนแสง หรือเงาบนผนังมาถึงก่อน → `-low` ตัวร้ายเต็มเฟรม แสงจากล่าง → `-high` เหยื่อเล็ก ที่ว่างเหนือหัว → `-ots` จากหลังตัวร้ายมองเหยื่อ (ตัวร้ายเป็นมวลดำ FG) → `-ecu` ตาเหยื่อ
- **Hierarchy of scale:** ในช็อตคู่ ผู้มีอำนาจอยู่ใกล้กล้องกว่า (ใหญ่กว่า เท้าต่ำกว่า: actor string `who@x,floorY` ให้ floorY มากกว่า) — ไม่ยืดตัวละคร ใช้ระยะแทน, px-per-cm ของคนที่อยู่ระยะเดียวกันต้องเท่ากัน (`art-direction.md`)
- **เส้นแบ่ง:** เสา วงกบ หรือขอบแสงตรงกลางเฟรม แยกสองคน = ความสัมพันธ์แตก
- ห้าม: เผยตัวร้ายด้วยช็อต two-shot ระดับสายตาสว่างๆ

### A4 · เดินทาง / ไล่ล่า / ยานพาหนะ
*งาน:* ความเปลี่ยว ระยะทาง และ "มีอะไรตามมา"
- มอเตอร์ไซค์: **ต้องใช้** `<SideRoadSet>` + `<Motorcycle rider={…}>` (CLAUDE.md ข้อ 11) — ท่าขี่ข้างแบบ `ghost-money` shot `021`; สร้างความหลากหลายด้วยกล้อง ไม่ใช่ด้วยท่าใหม่
- **Pattern ถนนเปลี่ยวกลางคืน:** `-ew`/`-high` ยานพาหนะเล็กบนถนนยาว ไฟหน้าเป็นแหล่งแสงเดียว (`Beam`) → `-wide` tracking pan + parallax (เสาไฟ FG วิ่งผ่าน) → `-close` หน้าคนขี่/คนขับ ฝนตก (`Rain`/`RainStreaks`) → `-mirror` กระจกมองหลัง: มีแสงไฟ/คนนั่งข้างหลังที่ไม่ควรมี → `-pov` กระจกหน้า ที่ปัดน้ำฝน
- กระจกมองหลังคือ **อุปกรณ์ twist ประจำเรื่องผีไทย** (ผู้โดยสารที่ไม่มีในกระจก / มีในกระจกแต่ไม่มีบนเบาะ) — วางให้เห็น 3 ครั้งก่อนเฉลย
- ไล่ล่า: เพิ่ม shake, ช็อตสั้นลง (2–3 beats), สลับ `-low` (ผู้ไล่) กับ `-high` (ผู้หนี)
- รถยนต์ภายในยังไม่มีใน kit: วาดใน episode ก่อน แล้วย้ายเข้า `src/kit/places.tsx` เมื่อเรื่องที่สองต้องใช้ (CLAUDE.md ข้อ 6)

### A5 · ย้อนอดีต / Twist clue re-read
*งาน:* คนดูต้องรู้ทันทีว่า "นี่คืออดีต" และตอนเฉลยต้องจำได้ว่า "เคยเห็นภาพนี้แล้ว"
- **เกรด:** `data.past: true` → `PAST_FILTER` (ซีดอมน้ำตาล) + grain 0.24 อัตโนมัติ; ปัจจุบันโทนเย็น (`night`/`dim`), อดีตโทนอุ่นซีด — **ห้ามสลับ** ตลอดทั้งเรื่อง
- **มุมกล้องของอดีต:** แคบกว่าปัจจุบันหนึ่งขั้น + vignette หนักกว่า (ความทรงจำไม่เห็นรอบด้าน), กล้องนิ่งกว่า หรือมุมสูงเล็กน้อย (มองย้อนลงไป)
- **Mirror framing (กฎสำคัญที่สุดของ twist):** ช็อตเฉลยใช้ **`data.cam` และตำแหน่งนักแสดงเดียวกับช็อตที่ปลูกเบาะแส** แต่ตอนนี้สิ่งที่ขาดไปปรากฏ (คนที่ยืนอยู่ตลอด, มือที่มีแผล, เงาที่ไม่มี) — ใส่หมายเลขช็อตต้นทางไว้ใน clue table ของ `brief.md`/outline
- **Re-read montage:** ช็อตละ 2 beats, setup เดิมของต้นฉบับ, ข้อความสั้นหนึ่งบรรทัด
- ตัดเข้า/ออกอดีตด้วย cut ตรง + cue `whoosh` หรือ `flip`; ห้าม fade ทุกครั้ง (`art-direction.md` banned)

### A6 · ซักถาม / สารภาพ / บทสนทนาที่มีคนโกหก
*งาน:* ให้คนดูจับได้ก่อนตัวละคร
- **Pattern:** `-wide` สองคนโต๊ะเดียว หลอดไฟดวงเดียว (S11) แสงแบ่งกลางโต๊ะ → `-ots` สลับฝั่ง → `-close` คนตอบ → **ตอนโกหก:** `-ecu`/`-ins` "tell" (มือบีบ, นิ้วเคาะ, สายตาหลบ) → `-close` คนถาม (เขาเห็นหรือไม่เห็น)
- ให้ผู้ต้องสงสัยแต่ละคนมี **tell ประจำตัวหนึ่งอย่าง** ที่เป็นภาพ (insert) — ใช้ทุกครั้งที่เขาโกหก และไม่ใช้เมื่อพูดจริง (fair play)
- **Split lighting:** หน้าครึ่งมืดครึ่งสว่าง (`rim=l`/`rim=r` + `LightMask` เยื้อง) สำหรับคนสองหน้า
- เส้น 180°: คนถามซ้าย คนตอบขวา ตลอดฉาก (`story` เตือนเมื่อ x กระโดด) — **ข้ามเส้นโดยตั้งใจ** ได้ครั้งเดียวตอนบทสนทนาพลิก (คนถามกลายเป็นผู้ถูกกล่าวหา)

### A7 · ถูกจับตามอง / ความระแวง / ถูกสะกดรอย
*งาน:* คนดูรู้ว่ามีคนดูอยู่ ตัวละครไม่รู้ (dramatic irony)
- **Pattern:** `-fif` จากหลังม่าน/มุ้ง/ต้นไม้ ตัวละครเล็กไม่รู้ตัว → `-close` ตัวละครหยุด หันมา → `-pov`/`-ew` สิ่งที่เขาเห็น: ว่างเปล่า (ที่ว่างสีดำตรงที่เพิ่งมีคน) → `-dutch` เมื่อเขาเริ่มไม่ไว้ใจโลก
- **Negative space behind:** ประตูมืดหรือทางเดินว่างข้างหลังตัวละคร กินพื้นที่ ≥ 40 % ของเฟรม — คนดูจะจ้องที่ว่างนั้นเอง
- ช็อต voyeur ถ้าเป็นของตัวร้ายจริง ให้กล้อง sway (S13); ถ้าเป็นแค่ความระแวง ให้นิ่ง

### A8 · ค้นในที่มืด / เข้าห้องต้องห้าม
- **Pattern:** `-wide` ประตู/ทางเข้า ด้านในดำ → `-pov` ไฟฉาย (`Beam` + `beamAt` keys) ส่องกวาด เผยทีละส่วน → `-close` หน้าคนส่องในแสงสะท้อน → `-ins` สิ่งที่ไฟฉายเจอ
- แสง = สิ่งที่คนดูได้รู้; นอกลำแสงต้องมืดจริง (`Grade dark`, `LightMask`) ห้ามเห็นทุกอย่างก่อนไฟส่อง
- Thai: ทางเดินวัด (`Corridor`), ใต้ถุนบ้าน (`StiltHouse`), โถงหอพัก (`DormHall flick`), โรงพยาบาล (`HospitalHall off`)

### A9 · การค้นพบ (ศพ / ของที่ไม่ควรอยู่ตรงนั้น)
- **Pattern:** `-close` หน้าคนเห็นก่อน (ยังไม่เห็นสิ่งที่เขาเห็น — 1 ช็อต) → `-snap` หรือ `-high` สิ่งที่พบ (มุมสูงทำให้ดูไร้ทางสู้และสิ้นสุด) → `-top` ผ้าคลุม/โครงร่าง/ของกระจาย (ไม่ต้องโชว์ศพตรงๆ)
- เสียง: `hush` หนึ่งช็อตก่อน แล้ว `hit` บนภาพ

### A10 · พิธีกรรม / สถานที่ศักดิ์สิทธิ์ (ศาลพระภูมิ, วัด, ศาลาสวดศพ, เมรุ)
*งาน:* ระเบียบ → ระเบียบถูกทำลาย
- **Symmetry:** จัดกลางเฟรม สมมาตรซ้ายขวา (โต๊ะหมู่บูชา, ประตูโบสถ์, ศาลพระภูมิ) กล้องระดับสายตาตรงหน้า = ศักดิ์สิทธิ์ เป็นระเบียบ
- **ทำลายสมมาตร** เมื่อสิ่งเหนือธรรมชาติเข้ามา: ตัดไป `-dutch` หรือเลื่อนเฟรมให้เสียสมดุล, เทียนดับด้านหนึ่ง
- ควันธูป เทียน = แสงอุ่นจุดเดียว (`lantern`/`lamp`); หลังโต๊ะหมู่ = ที่ซ่อน (`altar-back` ใน `ghost-money`)

### A11 · โลกภายนอก / ชาวบ้าน / ข่าว / ตำรวจ (Living world)
- **Chorus:** หน้าชาวบ้าน 3–4 คนเรียงแบบ close ทีละคน 2 beats (ซุบซิบเป็นจังหวะ) หรือ `-fif` ผ่านหน้าต่างร้าน
- ข่าวทีวี/วิทยุ: `news` card หรือจอทีวี FG มืด ข่าววิ่งสว่าง ตัวละครดูจาก MG
- สถานีตำรวจ: แสงขาวเย็น แฟลตกว่า สว่างกว่าทุกฉาก (ระบบ = ไม่มีที่ซ่อน) — ใช้ความต่างนี้เป็นจังหวะพัก

### A12 · รอคอยก่อนพายุ / ความเงียบก่อน twist
- `-ew` hold หรือ push ช้ามาก, negative space, ไม่มีการ์ด, `hush` — ช็อตเดียว 3 beats (เพดานความเงียบใน `longform-rules.md`)
- แล้ว **ตัดไปขนาดตรงข้ามทันที** (`-ecu`/`-snap`) — contrast คือสิ่งที่ทำให้ twist กระแทก

### A13 · เฉลย Twist (The reveal frame)
- เฟรมที่มืดที่สุดของเรื่อง (`art-direction.md` arc), setup ที่ **ยังไม่เคยใช้** ในเรื่อง หรือ mirror framing ของช็อตปลูก (A5)
- 4 beats, `bighit` beat 0, `voLead` ≈ 0.5, red box; หลักฐานใหญ่และชัด (blur-to-sharp, flip)

### A14 · ผลที่ตามมา / โศกเศร้า (Aftermath)
- แสงเช้า (`morning`/`dawn`), `-high`/`-ew` pull-out ช้า ตัวละครเล็ก; กล้องนิ่ง สงบ — ความต่างจากความมืดของฉากเฉลยคือรางวัลทางอารมณ์

## 4. Dynamic Decision Heuristic — AI ตัดสินใจเลือกมุมเอง

### 4.1 สามคำถามก่อนเลือก setup ทุกช็อต

1. **ช็อตนี้เป็นของใคร?** (ใครเป็นเจ้าของสายตา) → ถ้าเป็นของตัวละคร: POV/OTS/close ของเขา; ถ้าเป็นของผู้เล่าเรื่อง: wide/top/fif
2. **คนดูรู้มากกว่าหรือน้อยกว่าตัวละคร?** → รู้มากกว่า (dramatic irony): `-fif`, `-high`, negative space ที่มีภัย; รู้น้อยกว่า (mystery): `-close`, `-ins` ตัดบางส่วน, `-sil`, ไฟฉาย
3. **ใครมีอำนาจในวินาทีนี้?** → ผู้มีอำนาจ `-low`/ใกล้กล้อง/ FG; ผู้ไร้อำนาจ `-high`/ไกล/เล็ก; เท่ากัน: EYE

ถ้าตอบทั้งสามข้อแล้วได้ "ผู้เล่า / รู้เท่ากัน / อำนาจเท่ากัน" → EYE ได้ นอกนั้น **ต้องไม่ใช่ EYE**

### 4.2 ตาราง trigger — เหตุการณ์แบบนี้ ➔ เปลี่ยนมุมทันที

| เหตุการณ์ในบท | Setup บังคับ (เลือกหนึ่ง) | ทำไม |
|---|---|---|
| ตัวละครโกหก / ปิดบัง | `-ecu`/`-ins` บน tell, split lighting, `-mirror` | ให้คนดูจับได้ก่อน |
| เพิ่งรู้ว่ามีคนโกหก / ความไว้ใจแตก | `-dutch` (เริ่มจากช็อตนี้ถึงจบฉาก), เส้นแบ่งกลางเฟรม | โลกเอียง |
| ความระแวง / รู้สึกถูกจับตา | `-fif`, negative space ข้างหลัง, `-pov` ที่ว่างเปล่า | คนดูจ้องที่ว่าง |
| เบาะแสถูกพบ / ถูกมองครั้งแรก | `-ins` macro + แสงจุดเดียว; ครั้งต่อไปกรอบเดิม | "จำไว้" |
| เบาะแสที่พลิกคดี (mini-reveal) | `-ecu` + push ชัด หรือ `-snap` (ถ้ายังเหลือโควตา) | ตระหนักรู้ |
| ตัวร้ายเผยตัว / ข่มขู่ | `-sil` → `-low` | อำนาจ |
| ตัวละครไร้ทางสู้ / ถูกต้อน / รู้สึกผิด | `-high`, `-ew` | เล็กลง |
| ตัวละครตัดสินใจครั้งใหญ่ | `-close` → `-low` เล็กน้อยบนตัวเขาเอง | ได้อำนาจคืน |
| เสียงจากที่มองไม่เห็น (โทรศัพท์, ห้องข้างๆ, วิทยุ) | `-close` คนฟัง + ภาพของแหล่งเสียงแบบ `-ins`/`-sil` ไม่เห็นหน้า | ภัยไร้รูป |
| ข้อมูลใหม่จากภายนอก (ข่าว, เอกสาร, ตำรวจ) | `-ins`/CARD, `-top` | หลักฐาน |
| ย้อนอดีต | `data.past` + แคบลงหนึ่งขั้น / mirror framing | แยกเวลา |
| ความเงียบก่อนพายุ | `-ew` hold + `hush` แล้วตัดไป `-ecu`/`-snap` | contrast |
| สิ่งศักดิ์สิทธิ์ถูกละเมิด | สมมาตร → `-dutch` | ระเบียบพัง |
| เดินทาง / เวลาผ่าน | `-ew`/`-high` + tracking pan | ระยะทาง |
| ชัยชนะทางศีลธรรม / จบ | `-high` pull-out แสงเช้า | ปลดปล่อย |

### 4.3 บันไดระดับความรุนแรงของภาพ (Escalation ladder)

| ระดับ | เครื่องมือ | ใช้กับ |
|---|---|---|
| 0 | EYE wide / med, push ช้า | ข้อมูล, กติกา, ช่วงพัก |
| 1 | `-close` `-ins` `-ots` `-top`, push ชัด, rack focus | อารมณ์, เบาะแส, บทสนทนาที่มีแรงกดดัน |
| 2 | `-low` `-high` `-sil` `-fif` `-pov` `-mirror` `-cctv` `-split` `-dutch`, chiaroscuro | อำนาจเปลี่ยน, ระแวง, ภัย, mini-reveal |
| 3 | `-snap`, rim แดง (`rim=red`), เฟรมมืดที่สุด, mirror framing ของเฉลย | ช็อตพลิกเรื่องเท่านั้น — จำนวนเท่ากับ red box (Shorts 2–4, เรื่องยาว 3–5) |

- ขึ้นได้ทีละขั้นตามแรงกดดันของบท; **ห้ามกระโดดจาก 0 ไป 3** ยกเว้น jump scare ที่ตั้งใจ (และมีช็อตเงียบ A12 นำ)
- หลังระดับ 3 ให้ลงมาที่ 0–1 อย่างน้อยหนึ่งช็อต (ให้คนดูหายใจ) ก่อนขึ้นอีก
- ระดับ 2 ที่ใช้พร่ำเพรื่อจะกลายเป็นระดับ 0 — ดูโควตาข้อ 6

## 5. Layering Rule — สามชั้น FG / MG / BG

ภาพ 2D แบนเพราะทุกอย่างอยู่ระนาบเดียวและคมเท่ากัน ทุกช็อตที่เป็น set (ไม่ใช่การ์ด/insert เต็มจอ) ต้องมี **อย่างน้อย MG + BG** และช็อตระดับ 1 ขึ้นไป **ควรมี FG**

| ชั้น | อะไร | ความคม | ค่าสี/แสง | ขนาด | การเคลื่อน (parallax) |
|---|---|---|---|---|---|
| **FG** (หน้า) | ขอบประตู, มุ้ง, ไหล่คน (OTS), ขอบโต๊ะ, เสาไฟ, ใบไม้, ลูกกรง, ฝนใกล้กล้อง | เบลอ `blur(5–10px)` | มืดกว่า MG 40–70 % (เกือบ silhouette) ไม่มี rim | ใหญ่ ตัดขอบเฟรม กิน 10–35 % ของภาพ ห้ามบังหน้า/เบาะแส | 1.3–1.6× ของกล้อง |
| **MG** (กลาง) | ตัวละคร, เบาะแส, สิ่งที่เรื่องพูดถึง | คมที่สุด | contrast สูงสุดในเฟรม + rim light (`data.rim`) + `FloorShadow` | ตาม px-per-cm ของฉาก | 1× (อยู่ใน `Cam`) |
| **BG** (หลัง) | ผนัง, ท้องฟ้า, ทุ่ง, ตึกแถวไกล | `<Far blur={4–8}>` | contrast ต่ำ: กลางวันสว่างและซีดกว่า, กลางคืนมืดกว่า, สีเอียงไปทางเกรด | | 0.5–0.7× |

- **Value separation:** MG ต้องแยกจาก BG ได้แม้ภาพเป็นขาวดำ (หรี่ตาดู Board frame ที่ 360 px) — ถ้าไม่แยก: เพิ่ม rim, หรี่ BG, หรือวาง `Glow` หลังตัวละคร
- **FG ห้ามเข้าโซน caption/subtitle** เป็นองค์ประกอบสำคัญ แต่ให้ set ไหลต่อลงขอบล่างได้ (`art-direction.md` safe zones)
- **ใส่ FG ใน prop `fore` ของ `Stage`**: วาดเป็นพิกัดเฟรม (ไม่ใช่พิกัดโลก) แล้ว Stage เบลอ หรี่ และเลื่อนให้มากกว่าโลก `1 + foreK` เท่าบน pan และขยายเร็วกว่าบน push ให้เอง; FG เอียงตาม `data.tilt` และได้ past filter ด้วย:

```tsx
<Stage p={p} presets={PRESETS} world={set}
  fore={<DoorEdge />}            // วงกบประตู / มุ้ง / ไหล่ OTS (พิกัดเฟรม 1920×1080 หรือ 1080×1920)
  foreK={0.4} foreBlur={7} foreDark={0.45} />
// scene ที่ไม่ใช้ Stage: <Fore shift={[dx, dy]} scale={s} blur={7} dark={0.45}>…</Fore>
```

- prop `over` ยังมีไว้สำหรับสิ่งที่ต้องอยู่นิ่งกับเฟรม (การ์ด, วงแดง) — ไม่เอียง ไม่ parallax
- BG parallax: วาดฉากหลังใน `Cam` ตัวที่สองด้วย `cx` ที่ขยับ 0.6× — ทำเมื่อมี pan หรือ tracking เท่านั้น (ช็อต push ธรรมดาไม่ต้อง)
- **Atmosphere เป็นชั้นที่สี่ได้:** ฝน (`Rain`), ฝุ่นในลำแสง (`Dust`), หมอก (`Glow` ขาวจางยาว) ระหว่าง MG กับ BG ช่วยให้ลึกขึ้นทันที
- FG ไทยที่ดี: มุ้ง, บานเกล็ดไม้, ซี่ระเบียง, เสาใต้ถุน, ตะเกียง, ผ้าม่านพลาสติกร้านค้า, กิ่งตะเคียน, ป้ายรถเมล์, กระจกเปียกฝน

## 6. Pacing & Contrast — กฎการสลับและโควตา

"setup เดียวกัน" = ช็อตติดกันที่ scene เดียวกัน และกลุ่ม/คำต่อท้ายเดียวกัน (view ไม่มีคำต่อท้ายนับเป็น `eye` ทั้งหมด — `sala:row` ตามด้วย `sala:desk` = ซ้ำ)

| กฎ | Shorts (9:16) | เรื่องยาว (16:9, ต่อ chapter) |
|---|---|---|
| setup เดียวกันติดกันสูงสุด | 1 (ห้ามซ้ำติดกัน — กฎ shot type เดิม) | 3 |
| `view` เดียวกันติดกันสูงสุด | 1 | 4 (กฎเดิม) |
| สัดส่วน EYE (flat side-view) | ≤ 40 % | ≤ 50 % |
| สัดส่วน CLOSE (close/ecu/insert) | ≥ 30 % | ≥ 30 % |
| ANGLE (`low` `high` `top` `dutch`) | ≥ 3 ช็อต (มี low ≥ 1 และ high/top ≥ 1) | ≥ 1 ต่อ chapter ที่ยาวกว่า 90 s และทั้งเรื่อง ≥ 1 ต่อทุก 90 s; ทั้งเรื่องครบทั้ง low และ high/top |
| DEVICE (`ots` `pov` `fif` `sil` `split` `mirror` `cctv`) | ≥ 2 ช็อต | ≥ 1 ต่อ chapter ที่ยาวกว่า 90 s และทั้งเรื่อง ≥ 1 ต่อทุก 90 s |
| จำนวน setup ไม่ซ้ำ | ≥ 6 | ≥ 4 ต่อ chapter, ≥ 10 ทั้งเรื่อง |
| `-dutch` | ≤ 2 ช็อต | ≤ 3 % ของช็อต, ห้ามใน chapter ที่สงบ |
| ระดับ 3 (`-snap`, เฉลย) | 1–3 (ตาม red box) | 3–5 ทั้งเรื่อง |

**กฎจังหวะ:**
- **Size step:** ช็อตติดกันของ subject เดิมต้องเปลี่ยนขนาดภาพอย่างน้อยหนึ่งขั้น (wide → med → close → ecu) หรือเปลี่ยนมุม; zoom ต่างกัน < 25 % บน subject เดิมมุมเดิม = jump cut ห้ามใช้
- **The squeeze:** ฉากที่ความตึงเพิ่ม ให้ขนาดภาพแคบลงเรื่อยๆ ข้ามช็อต (wide → med → close → ecu); **release** ด้วยการตัดกลับไป wide หรือ high
- **Contrast cut:** ก่อนช็อตกระแทก (twist, jump, ตัวร้ายเผย) ให้ช็อตก่อนหน้าเป็นขั้วตรงข้าม — กว้าง/นิ่ง/เงียบ ก่อน แคบ/เร็ว/ดัง
- **Coverage ของบทสนทนา (ต่อจากกฎเดิม):** wide two-shot → OTS หรือ close ผู้พูด → ปฏิกิริยาผู้ฟัง → insert ของสิ่งที่พูดถึง; สลับฝั่ง OTS แต่ไม่ข้ามเส้น 180°
- **เวลาอ่านภาพ:** POV / FIF / split / CCTV ต้องได้ ≥ 3 beats (คนดูต้องเข้าใจกรอบก่อน); insert 2–3 beats; snap 2 beats แล้วตัด
- **Reveal ต้องใช้ setup ที่สดใหม่:** setup ของช็อตเฉลยไม่ควรถูกใช้ใน 10 ช็อตก่อนหน้า (ยกเว้น mirror framing ที่ตั้งใจซ้ำช็อตปลูก)
- **Pattern change 30–60 s (เรื่องยาว):** ช็อต ANGLE/DEVICE นับเป็น pattern change ได้

## 7. 9:16 vs 16:9

| | Shorts 9:16 (1080×1920) | เรื่องยาว 16:9 (1920×1080) |
|---|---|---|
| จุดแข็ง | แนวตั้ง: ตัวสูงตระหง่าน (`-low`), มองลงบ่อ/บันได (`-high`/`-top`), วงกบประตูแนวตั้ง (`-fif`), stack บน/ล่าง | แนวนอน: negative space ด้านข้าง, OTS, pan/tracking, split ซ้าย/ขวา, ทางเดินยาว |
| โซน action | y 160–1180 (caption ≈ 1390) | ใบหน้า/เบาะแสเหนือ y ≈ 840 (subtitle 220 px ล่าง) |
| split | บน/ล่าง เส้นแบ่งเหนือ caption | ซ้าย/ขวา |
| OTS | ไหล่ FG ที่ขอบล่าง-ข้าง (ไม่ใช่ข้างเต็ม) | ไหล่ FG ซ้ายหรือขวา 25–35 % |
| ขนาดหน้า | close ≥ 500 px, figure ที่สำคัญ ≥ 600 px | wide ≥ ~90 px, close ใหญ่ตามสูตร |
| ความถี่การเปลี่ยน setup | ทุกช็อต | ทุก 1–3 ช็อต |

## 8. Self-check — Visual Variety Audit

1. ตอนเขียน story.json: ทุกช็อตมี `view` ที่มีคำต่อท้ายจากข้อ 1 (หรือ scene แบบ insert/card) และทุก view ใหม่ได้ preset ใน scene
2. รัน `npm run shots -- episodes/<slug>` — พิมพ์ลำดับ setup, สัดส่วน EYE/CLOSE/ANGLE/DEVICE/CARD, setup ที่ซ้ำติดกันเกินกฎ, และโควตาในข้อ 6 (เรื่องยาว: ต่อ chapter) แก้ทุกบรรทัด `✗` ก่อนวาดฉาก
3. หลังวาด: เปิด Board frames / contact sheet แล้วถามแต่ละช็อต: *ชื่อ view บอกว่า low — ภาพดู low จริงไหม?* (ตัวเลขผ่านแต่ภาพแบน = ไม่ผ่าน), มีสามชั้นไหม, MG แยกจาก BG ที่ 360 px ไหม
4. ทุก trigger ในข้อ 4.2 ที่เกิดในบท ได้ setup ของมันไหม (ไล่ดูช็อตที่มีการโกหก, เบาะแส, ตัวร้าย, ย้อนอดีต)
5. ช็อตเฉลยใช้ setup สดใหม่หรือ mirror framing ของช็อตปลูก และหมายเลขช็อตทั้งสองอยู่ใน clue table

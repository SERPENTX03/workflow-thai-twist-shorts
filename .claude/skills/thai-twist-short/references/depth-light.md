# Depth & Light — กฎกันภาพแบน (Anti-flat) สำหรับฉาก 2D

ใช้กับทั้ง Shorts (9:16) และเรื่องยาว (16:9) อ่านไฟล์นี้ **ตอนวาดฉาก (step 4)** และ **ตอน review** ทุกช็อตที่เป็น set (ไม่ใช่การ์ด)

`directing.md` บอกวิธีคิดภาพ; `cinematography.md` บอกว่า **กล้องอยู่ที่ไหน**; ไฟล์นี้บอกว่า **ในเฟรมมีกี่ชั้น แสงมาจากไหน เงาตกทางไหน** ถ้าขัดกัน: CLAUDE.md, safe zone (`art-direction.md`), กฎมือ (`hands-poses.md`) ชนะเสมอ ตัวเลขทุกตัวในไฟล์นี้ (สัดส่วนเงา, FG %, blur) เป็น **แนวทางเริ่มต้น** ที่ `npm run look` ใช้เตือน — ภาพที่ดีและมีเหตุผลชนะตัวเลข

## 0. ภาพแบนเกิดจากอะไร (หลักฐาน)

`npm run look -- episodes/same-child` (400 ช็อต): ช็อตกลางวันมีเงาเฉลี่ย **7 %** ของเฟรม, ช็อตกลางคืน **39 %**, **127 ช็อตแสงเท่ากันทั้งเฟรม** (ไม่มีทิศ), 22 ช็อตมืดสนิทจนไม่มีอะไรถูกแสง (murky) ห้องนอนตีหนึ่งสว่างเท่ากับห้องตอนเที่ยง ทุกคนยืนบนเส้นพื้นเส้นเดียว ผนังขนานกับจอ และแทบไม่มีเงา

สาเหตุสามอย่าง: **ตัวละครยืนกลาง + ฉากหลังระนาบเดียว + แสงเท่ากันทั้งเฟรม** ทางแก้ที่ได้ผลที่สุดไม่ใช่แปะชั้นทับฉากหน้าตรง แต่คือ **สร้างสถานที่เป็นห้องสามมิติ** (`src/kit/room.tsx`) และ **กดโทนกลางด้วย `LightVeil` ให้เหลือแอ่งแสง** (ข้อ 4–5, `directing.md` §3–4) ตารางด้านล่างคืออาการของภาพแบนที่ต้องหาให้เจอใน Board frame

## 1. อาการภาพแบน 7 อย่าง (หาให้เจอแล้วแก้)

| # | ห้าม | ทำแทน | เครื่องมือ |
|---|---|---|---|
| R1 | ตัวละครหลักคนเดียว **ยืนกลางจอ** ในช็อตระดับสายตา (EYE) | วางบนเส้น **1/3** (16:9: x จอ ≈ 640 / 1280 · 9:16: ≈ 360 / 720) ที่ว่าง (negative space) อยู่ฝั่งที่เขามอง หรือฝั่งที่ภัยจะมา | ข้อ 3 |
| R2 | ฉากมีแค่ **ตัวละคร + กำแพง** (1–2 ระนาบ) | **4 ชั้น** FG / MG / BG / ATMO | ข้อ 2 |

| R5 | **เท้าลอย** ไม่มีเงา | เงาสัมผัสพื้นใต้เท้า + **เงาทอดยาว** หนีจากแสง | ข้อ 6 |

| R7 | **Standing Cutout:** ตัวละครยืนหน้าตรงทื่อ แขนแนบลำตัวเหมือนหุ่นกระดาษ | Staging ทางกายภาพ: นั่งคุดคู้ (`crouch`), นั่งขอบเตียง (`sit`), หันหลังมองภัย (`back`), หรือหันข้างถือไฟฉาย (`r-hold`) | ข้อ 3, 7 |

ข้อยกเว้นที่ตั้งใจ (เขียนเหตุผลไว้ในคอมเมนต์ของ scene): สมมาตรของสถานที่ศักดิ์สิทธิ์ก่อนถูกทำลาย (`cinematography.md` A10), `-low` ตัวร้ายเต็มเฟรม, การ์ด/แผนที่/กฎ, ช่องของ `Split` (แต่ละช่องจัดเฟรมเอง), ผี/ตัวเอกที่เป็นผี **ไม่มีเงา** (เป็นเบาะแส — `noShadow`), ภาพ CCTV ที่มืดสนิทโดยตั้งใจ

**สว่าง ≠ แบน:** ฉากกลางวันของ Shorts สว่างได้ตามปกติ (`art-direction.md`: ความมืดเก็บไว้ช่วงพลิก) แต่ยังต้องมีทิศแสง เงาทอด และ perspective — R3 กลางวันไม่บังคับความมืด บังคับแค่ "แสงมาจากด้านหนึ่ง"

## 2. สถาปัตยกรรม 4 ชั้น (ด้วย kit ที่มีจริง)

| ชั้น | อะไร | ทำอย่างไร | ค่า |
|---|---|---|---|
| **FG** หน้าสุด | เสาไฟ, สายไฟพาดขอบบน, กิ่งตะเคียน, วงกบประตู, บานเกล็ด, มุ้ง, ลูกกรง, ไหล่คน (OTS), แฮนด์/กระจกมองข้างมอเตอร์ไซค์, กระจกเปียกฝน | `Stage` prop `fore` (พิกัดเฟรม) — Stage เบลอ หรี่ และ parallax ให้; scene ที่ไม่ใช้ Stage: `<Fore shift scale blur dark>` (`stage.tsx`) | blur 6–10, `foreDark` 0.45–0.6, กิน 10–35 % ของเฟรม, `foreK` 0.4 (≈ 1.4× กล้อง) |
| **MG** โฟกัส | ตัวละคร, เบาะแส, ยานพาหนะ | `Actors` (wrapper ของ episode) — rim อัตโนมัติจาก `data.rim`/`data.light` (`rimFilter`), เงาจาก `data.lightAt` | คมที่สุด สว่าง/contrast สูงสุดในเฟรม |
| **BG** โครงสร้าง | ตึกแถว, กำแพงวัด, ศาลา, แนวต้นไม้, ผนังห้อง | set ใน `<Far blur dim>` (`fx.tsx`); ผิวต้องมีลาย: `Planks`, คราบน้ำ (gradient แนวดิ่ง), ป้าย, รอยแตก | blur 3–6; กลางคืน `dim` 0.5–0.7 (มืดกว่า MG 30–50 %) |
| **ATMO** บรรยากาศ | ท้องฟ้าไล่เฉด, หมอก, ฝุ่นในลำแสง, ฝน | `Sky` (gradient), `Haze` (`depth.tsx`), `Dust` / `Cone` (`light.tsx`), `Rain` / `RainStreaks`, `Glow` ขาวจางยาว | `Haze` a 0.12–0.25 ระหว่าง BG กับ MG |

- MG + BG + ATMO ทุกช็อต set; **FG เมื่อภาพมีเหตุผลให้มี** — แอบมอง/ถูกจับตา, ข้ามไหล่, ถูกขัง, ความลึกของภาพกว้างกลางคืน (ราว 1/3 ของช็อตทั้งเรื่อง) FG ต้องเป็นของที่มีอยู่ในสถานที่นั้นจริง (วงกบ มุ้ง เสา ไหล่คน) ไม่ใช่ก้อนดำเบลอที่แปะให้ครบ
- **FG ที่เป็นเงาดำต้องตัดกับของที่สว่างข้างหลัง** — เสาดำหน้ากำแพงมืดหายไปเฉยๆ (บทเรียนจาก demo `anti-flat`) วาง FG ให้เฉือนขอบของวงแสงหรือหน้าต่างที่สว่าง
- FG ห้ามทับหน้า เบาะแส และแถบ caption/subtitle
- **ลำดับในฉาก** (ล่าง → บน): `Sky` → BG set (`Far`) → `PerspFloor`/`SideWall` → `Haze` → แสง (`Cone`, `Glow` — `mixBlendMode: 'screen'`) → เงา → `Actors` → (Stage ทำต่อเอง) `fore` → `Grade` + vignette → `over` (การ์ด, วงแดง) → grain, HUD
- ความแยกชั้น: หรี่ตาดู Board frame ที่ 360 px (Shorts) / 480 px (contact sheet) — MG ต้องแยกจาก BG ได้แม้เป็นขาวดำ

## 3. วางตัวละครบนเส้น 1/3 และ Staging ที่มีชีวิต (เลิกใช้ Standing Cutout)

**ห้ามตัวละครยืนตัวตรงหน้าตรง (Default Stand) ในช็อตระทึก/สยอง:** ตัวละครยืนทื่อหน้าตรงจะดูเหมือนหุ่นกระบอกที่ถูกวางแปะลงบนฉากทันที
- **Physical Staging:** ในฉากระทึกขวัญ ให้ใช้ท่าทางที่มีเจตนาชัดเจน:
  * นั่งคุดคู้พิงผนัง: `"actor@420 crouch scared o=0.9"`
  * นั่งขอบเตียงหันข้าง: `"actor@1320 sit worried flip"`
  * หันหลังมองสิ่งผิดปกติ: `"actor@640 back wary"`
  * ถือไฟฉายส่องสำรวจ: `"actor@1280 stand wary arm=r-hold prop=flashlight"`
- ตำแหน่งบนจอของจุด world `x` = `W/2 + (x − cx) · z` (`Cam` ใน `stage.tsx`) ถ้าอยากให้นักแสดงที่ `x` ไปอยู่ที่เส้น 1/3:
- เส้นซ้าย (W/3): `cx = x + W / (6z)` · เส้นขวา (2W/3): `cx = x − W / (6z)`
- 16:9 ที่ z 1.0: cx = x ± 320 · ที่ z 1.8 (close): cx = x ± 178 · 9:16 (W 1080) ที่ z 1.0: cx = x ± 180
- **Lead room:** หันหน้าเข้าหาที่ว่าง (`flip` ถ้าต้อง) ที่ว่างที่ "ไม่มีอะไร" แต่มืด = คนดูจะจ้องเอง (`cinematography.md` A7)
- two-shot: คนพูดบนเส้นหนึ่ง คนฟังบนอีกเส้น หรือเป็น FG แบบ OTS; ผู้มีอำนาจใกล้กล้องกว่า (A3)
- `npm run look` แจ้ง "dead centre" เมื่อ story.json มี `data.cam` และมีนักแสดงคนเดียวที่อยู่ในกลาง ±6 % ของจอ (preset ในไฟล์ scene ตรวจจากภาพไม่ได้ ต้องดู Board เอง)

## 4. แสง: แหล่งเดียว และความมืดตามอารมณ์

**แหล่งแสงที่ชี้ได้** (วาดให้เห็นในเฟรม หรือให้เห็นผลของมันชัด): หลอดไฟห้อย `Bulb`, ตะเกียง/โคม/เสาไฟถนน `Cone` (+ ฝุ่นในลำ), ไฟฉาย `Beam` + `LightMask` + `beamAt`, ไฟหน้ารถ `Beam angle={90}`, จอมือถือ `Glow` สีฟ้าเย็น `170,200,255` ใต้คาง, หน้าต่าง/ประตูเปิด (rect สว่าง + `Glow`), จอทีวี, เทียน/ธูป `Glow` อุ่นเล็ก

**`data.lightAt: [x, y]`** (พิกัด world ของแหล่งแสงนั้น) ทำสามอย่างให้อัตโนมัติ: นักแสดงที่มีชีวิตทุกคนทอด `CastShadow` หนีจากแสง, rim ไปอยู่ฝั่งที่หันเข้าหาแสง (ถ้าไม่ได้ตั้ง `data.rim`), vignette ของ `Grade` เอนไปทางแสง — **ค่าต้องตรงกับแสงที่วาดอยู่จริง** ไม่งั้นเงาจะชี้ผิดทาง ตั้ง vignette เองได้ด้วย `data.focus: [x, y]` (0–1 ของจอ)

| อารมณ์ | `data.light` | เงาในเฟรม (`npm run look`) | ทำอย่างไร |
|---|---|---|---|
| กลางวัน / ข้อมูล / กติกา | `day` `morning` `warm` `dusk` | ไม่บังคับ — แต่ต้องมีทิศ (ด้านสว่าง/ด้านมืด ≥ 1.25×) | แดด/หน้าต่างด้านเดียว, `CastShadow` สั้น-กลาง, `Far` blur อย่างเดียว |
| กลางคืน / ภายในบ้านมีไฟ | `night` `lamp` `lantern` | **≥ 45 %** | ไฟดวงเดียว (`Cone`/`Bulb`) + `lightAt`, `Far dim 0.6`, `Haze` เบาๆ, เลิกใช้ `Glow` ใหญ่ที่เติมทั้งห้อง |
| ระทึก / สยอง / ซักถาม / สารภาพ | `dim` `dark` `noir` | **≥ 60 %** (เป้า 60–75 %) — แต่ **ตัวละครต้องถูกแสง** (ไม่ murky) | `noir` = วงแสงเดียว ที่เหลือดำ + `lightAt`/`focus` บนหน้าหรือเบาะแส, rim ชัด, FG บังขอบ |
| เฉลย (red box) | `noir` / `dark` + `rim=red` | **มืดกว่าค่ากลางของทั้งเรื่อง** | เฟรมที่มืดที่สุดของเรื่อง (`art-direction.md` arc) |
| หลังเหตุการณ์ / จบ | `morning` `dawn` | ไม่บังคับ | แดดต่ำด้านเดียว → `lightAt` ต่ำ = เงายาวสวย, pull-out |

- **ความมืดที่ดีมาจากแอ่งแสง ไม่ใช่จากเกรด:** ผนังโทนกลางค่อนมืด → แสงจริงในฉาก (หน้าต่าง หลอดไฟ จอ) → `<LightVeil id lights={[[x, y, r], …]} o>` (`src/kit/room.tsx`) กดทุกอย่างลง ยกเว้นรูตรงแสงตก → `Glow` ทับที่ตัวแหล่งแสง → `Dust` ในลำแสง รูแต่ละรูขนาดเท่าแอ่งแสงจริง (รูใหญ่เท่าผนัง = แบน), `o` ~0.3 ภาพกว้างที่ต้องเห็นพื้น, 0.4–0.55 ที่อื่น; ถ้าใช้ `Stage` + เกรดกลางคืนด้วย ลด `o` ลงเพราะเกรดหรี่ทับอีกชั้น ตัวละครที่ยืนในแสงวาด **หลัง** veil (สว่างเต็ม) คนที่อยู่ในความมืดวาดก่อน veil
- **ห้าม murky:** เฟรมดำ ≥ 90 % ที่ไม่มีอะไรถูกแสงเลย = คนดูมองไม่เห็นอะไร ช็อตมืดต้องมีวงแสงบนสิ่งที่เรื่องพูดถึง (หน้า, มือ, จอ, เบาะแส)
- จอมือถือในห้องมืด **คือแหล่งแสง** ต้องสว่างกว่าทุกอย่างในเฟรม ไม่ใช่สี่เหลี่ยมกรมท่าทึมบนพื้นดำ
- ไฟกะพริบใช้ `flicker(f, seed)` (`horror.tsx`) คูณกับ `a` ของแสงนั้น — deterministic

## 5. Perspective: เส้นเข้าหาจุดเดียว

| ชิ้น | ใช้ | ค่า |
|---|---|---|
| **`makeRoom` + `RoomShell` / `RFace` / `RBox` / `standAt`** (`room.tsx`) | **ภายในทุกแบบ — วิธีหลัก**: ผนัง พื้น เพดาน เฟอร์นิเจอร์ และตำแหน่งคนอยู่ใน perspective เดียวกัน กล้องย้ายไปไหนก็ยังถูก | `makeRoom(vp, back, depth 3.2–3.5)`; VP ไม่อยู่กลาง; มุมต่ำ/สูง = `makeRoom` ที่ `vp.y` ต่ำ/สูง |
| `<PerspFloor vx vy />` | ใส่ทับพื้นเดิมของ set ไหนก็ได้ (ไม่ใส่ `c0` = วาดแค่เส้นตะเข็บและแถว) หรือเป็นพื้นเองด้วย `c0`/`c1` | `vy` = ระดับสายตากล้อง (ต้องอยู่เหนือเส้นพื้น): ต่ำใกล้พื้น = กล้องต่ำ (`-low`), สูง = มองลง; `seams`, `rows`, `a` |
| `<SideWall side x top vx vy />` | ผนังข้างของห้อง/ทางเดิน/ซอย วิ่งจากผนังหลังที่ `x` ออกไปขอบเฟรม | `opening={[t0, t1]}` = ประตูมืดบนผนัง (ที่ซ่อนของภัย), `studs` = เสา/ไม้กระดาน, `light` 0–1 = ผนังฝั่งที่แสงตก |
| `DarkPassage view="passage"` (`passage.tsx`) | ทางเดินแคบมีจุดรวมสายตา (ตัวอย่างที่ทำไว้แล้ว) | |
| keystone `perspective(1400px) rotateX(±8–12deg)` | `-low` / `-high` บนเลเยอร์ตัวละครหรือตึก | `cinematography.md` S6/S7 |

- **จุดรวมสายตาเดียวต่อช็อต**: ทุกชิ้นในฉากใช้ `vx, vy` เดียวกัน
- วาง VP ฝั่ง negative space (สายตาวิ่งไปที่ว่าง) หรือหลังตัวละคร (ดึงความสนใจมาที่เขา) — ไม่ใช่กลางจอทุกช็อต
- ฉากที่วาดเป็นระนาบหน้าตรง (`ShopRow`, `Planks` + `Boards`, ห้องใน village.tsx) ได้มิติทันทีด้วย `PerspFloor` ทับพื้น + `SideWall` หนึ่งข้าง

## 6. เงา: ไม่มีเท้าลอย

- **เงาสัมผัส:** `Actors` วาด `FloorShadow` ใต้ทุกคนที่มีชีวิตอยู่แล้ว; scene ที่วาดเองใช้ `ShadowBlob` (`fx.tsx`) หรือ `FloorShadow`
- **เงาทอดยาว:** `<CastShadow x y h light={[lx, ly]} />` (`depth.tsx`) — ยาวเมื่อแสงต่ำหรืออยู่ไกลด้านข้าง, สั้นเมื่อแสงอยู่เหนือหัว, เอียงลงหากล้องเล็กน้อยให้อ่านว่าอยู่บนพื้น; `Actors` วาดให้ทุกคนเมื่อมี `data.lightAt`
- เงาทุกอันในช็อต **ชี้ออกจากแสงเดียวกัน** — เงาสองทิศ = แสงสองดวง = ภาพหลอก
- สิ่งของบนพื้น (โต๊ะ, รถ, มอเตอร์ไซค์, กล่อง) ก็ต้องมีเงา: `CastShadow` ด้วย `h` ของมัน หรือ `ShadowBlob`
- เงาบนผนังที่มาถึงก่อนตัว (`cinematography.md` S10) = silhouette เฉือน (skew) บนผนัง ไม่ใช่ `CastShadow`

## 8. อย่าลอกโค้ดตัวอย่างจากภายนอกโดยไม่ตรวจ

ข้อผิดพลาดที่เจอในโค้ดฉาก "ภาพยนตร์" ที่ได้มา:

- `background: 'polygon(...)'` ไม่ใช่ CSS — รูปทรงใช้ `clipPath: 'polygon(...)'` (ดู `Cone` ใน `light.tsx`)
- object style ที่มี `background` สองครั้ง: ตัวแรกหายเงียบๆ และ TypeScript error — ใส่ครั้งเดียว
- SVG attribute `filter="blur(4px)"` ไม่ทำงาน — ใช้ `style={{filter: 'blur(4px)'}}` หรือ SVG `<filter>`
- `zIndex` ข้ามชั้นของ Stage ไม่มีผล: ลำดับคือ world → fore → Grade → over; จัดลำดับด้วยตำแหน่งใน JSX
- `mixBlendMode: 'screen'` ทำให้สว่างเฉพาะสิ่งที่อยู่ข้างใต้มัน: แสงที่ต้องตกบนตัวละครให้อยู่เหนือ `Actors`, แสงบนฉากหลังให้อยู่ใต้
- ห้าม `Math.random()` / `Date.now()` (CLAUDE.md ข้อ 7) — ใช้ `rnd()`, `flicker()`

### แก้ช็อตที่ `npm run look` แจ้ง

| ✗ | แก้ |
|---|---|
| shadow (กลางคืน/ระทึกสว่างเกิน) | เกรดเข้มขึ้นหนึ่งขั้น (`night` → `dim` → `noir`), `Far dim`, ลบ `Glow` ใหญ่ที่เติมทั้งห้อง, เหลือแสงดวงเดียว + `lightAt` |
| flat (แสงเท่ากันทั้งเฟรม) | ย้ายแสงไปด้านหนึ่ง (`Cone`/`Glow` เยื้อง), `data.focus` ไปฝั่งนั้น, `SideWall light` ฝั่งเดียว, เงาทอด |
| washed out (contrast ต่ำ) | ดำให้ลึกขึ้น (เกรด), rim ชัดขึ้น, `Far dim`, MG สว่างขึ้นด้วยวงแสงของมันเอง |

| centre (ยืนกลางจอ) | เลื่อน `cx` ของ `data.cam` ไป `x ± W/(6z)` หรือย้ายนักแสดง |

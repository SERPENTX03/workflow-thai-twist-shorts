# Twist engines — หักมุมให้หลากหลาย และให้พีคจริง (ใช้ร่วม long และ short)

`cold-read.md` วัดว่าคนดูเอ่ยชื่อคำตอบได้ไหม ไฟล์นี้ตอบคำถามที่มาก่อนนั้น: **หักมุมพลิกอะไร** และพลิกแบบที่ช่องทำมาแล้วหรือเปล่า เรื่องที่ซ่อนเบาะแสดีแต่ใช้สูตรเดิม คนดูประจำก็เดาได้จากฮุก เพราะเขาเดา*แนว*ของคำตอบได้ ไม่จำเป็นต้องรู้ชื่อ

## 0. ทำไมต้องมีไฟล์นี้ (2026-11-13)

ใน 11 เรื่องยาวแรก มี 5 เรื่องที่เฉลยว่าผีปลอมและคนทำ (ghost-money, night-shift-rules, rear-cam, bed-two, banana-soi) อย่างน้อย 6 เรื่องให้คนที่ใจดีหรือคนที่ให้งานเป็นคนร้าย และเกือบทุกเรื่องจบที่ตำรวจมาจับ คนดูประจำจึงรู้ตั้งแต่ฮุกว่าคำตอบน่าจะเป็น "คนใกล้ตัวใช้ตำนานบังหน้า" ที่เหลือคือการไล่ตัดชื่อ cold read ของ banana-soi ที่ 25 % ก็เดาแนวนี้แล้ว

เรื่องที่ผู้ใช้ชอบคือ **เที่ยวสุดท้าย หนึ่งล้านบาท** (`last-ride`, อยู่ใน git ที่ commit `a489959`) คนขับรับงานส่งของที่มีกฎ "ห้ามเปิดตู้" ชั้นแรกเฉลยว่าของในตู้คือวิญญาณ ชั้นที่สองคือสัญญาจะจบก็ต่อเมื่อหาคนขับคนใหม่ได้ ชั้นสุดท้ายคือเขาตายตั้งแต่ก่อนรับงาน และเพราะตายแล้วจึงได้งานนี้ จุดพีคจริงคือเขาเลือกขับต่อเพื่อให้เงินอีกครึ่งถึงเมีย ไฟล์นี้ถอดว่าเรื่องนั้นทำอะไรต่างไป แล้วทำให้มันใช้ซ้ำได้ **โดยไม่ต้องเป็นเรื่อง "ตายแล้วไม่รู้ตัว" ทุกครั้ง**

## 1. เครื่องหักมุม 8 แบบ (engine)

เลือกหนึ่งตัวเป็นตัวหลักของเรื่อง เขียนไว้ใน brief/outline และใน `story.json → twist.engine`

| id | พลิกอะไร | คำถามที่คนดูถาม → คำตอบที่ได้ | ตัวอย่างของเรา |
|---|---|---|---|
| `who` | ใครทำ | "ใครทำ" → คนที่ไม่คิดว่าจะเป็น | fifth-room, rain-night, same-child |
| `fake-ghost` | สิ่งลี้ลับเป็นของปลอม | "ผีมีจริงไหม" → คนจัดฉาก | ghost-money, rear-cam, bed-two, banana-soi |
| `what-lead` | ตัวเอกเป็นอะไร (ตาย, เป็นต้นเหตุ, เป็นตัวที่ถูกตามหา, ไม่ใช่คน) | "จะรอดไหม / ในตู้มีอะไร" → ตัวเอกเองคือคำตอบ | last-ride, locker-104 |
| `rule-for` | กฎมีไว้ปกป้องใครหรืออะไร | "ทำตามกฎแล้วจะรอดไหม" → กฎปกป้องสิ่งที่เรากลัว หรือกฎคือเหยื่อล่อ | night-shift-rules (บางส่วน) |
| `time` | เวลาหรือลำดับเหตุการณ์ | "เกิดอะไรขึ้นคืนนี้" → เรื่องนี้เกิดไปแล้ว, เป็นสองช่วงเวลา, หรือวนซ้ำ | — |
| `whose-story` | เรื่องนี้เป็นของใคร | "ตัวเอกจะทำสำเร็จไหม" → คนที่เราดูอยู่ไม่ใช่ตัวเอก หรือผู้เล่าเป็นคนในเรื่อง | — |
| `victim` | ใครเป็นเหยื่อจริง | "ใครจะถูกทำร้าย" → คนที่เราคิดว่าเป็นคนร้าย หรือคนที่ทำร้ายตัวเอง | father-ledger |
| `trap-exit` | ทางรอดคือกับดัก | "จะออกไปได้ไหม" → การออกคือสิ่งที่มันต้องการ หรือคนที่ช่วยออกคือคนที่ต้องการให้ออก | — |

**กฎการหมุนเวียน** (`npm run story` ตรวจจาก `universe/canon.json → episodes[*].twist`):

1. engine ห้ามซ้ำกับ **สองเรื่องก่อนหน้า**
2. `fake-ghost` หรือ `supernatural: "fake"` ได้ไม่เกิน **1 ใน 4 เรื่องติดกัน**
3. บทบาทคนร้าย (`culprit`) ห้ามซ้ำเรื่องก่อนหน้า และ `helper` กับ `employer` รวมกันได้ไม่เกิน **1 ใน 3 เรื่องติดกัน**
4. รสหลัก (`flavour`, §3) ห้ามซ้ำสองเรื่องก่อนหน้า
5. ตอนจบแบบ `justice` (จับได้ ความจริงเปิด) ห้ามติดกัน **3 เรื่อง**

กฎพวกนี้เป็นคำถาม ไม่ใช่ข้อห้ามตายตัว ถ้าจะซ้ำ ให้เขียนเหตุผลบรรทัดเดียวใน brief (เช่น "ซ้ำ `who` แต่เฉลยชั้นสองเป็น `what-lead`") เพราะสิ่งที่คนดูจำได้คือแนวที่ช่องทำบ่อย

## 2. เฉลยเป็นชั้น (layers)

หักมุมที่มีชั้นเดียว เมื่อคนดูเดาถูกก็จบ หักมุมที่มีสองชั้น คนที่เดาถูกจะได้รางวัล แล้วถูกพลิกอีกครั้ง

- **ชั้น 1, ราว 40–55 %:** ยอมให้คำตอบที่คนดูเดาจากฮุก ("ในตู้คือผี", "ผีนี้ปลอม", "ลุงคนนี้มีเงื่อนงำ") บอกให้ชัดในภาพ ไม่ต้องหวง ชั้นนี้ปิดคำถามเก่าและเปิดคำถามใหม่ทันที
- **ชั้น 2, ราว 75–90 %:** ต้อง**เปลี่ยนคำถาม** ไม่ใช่แค่ตอบคำถามเดิมให้ลึกขึ้น ถ้าชั้น 1 ตอบว่า "อะไร" ชั้น 2 ต้องตอบเรื่อง "ใคร", "ทำไมต้องเป็นเขา" หรือ "ตัวเอกเองเป็นอะไร" เที่ยวสุดท้ายทำแบบนี้: ชั้น 1 บอกว่าในตู้คือผี ชั้น 2 พลิกจากของในตู้ไปเป็นตัวคนขับเอง
- **ทดสอบ:** ตัดชั้น 2 ทิ้งแล้ว เรื่องยังจบได้ไหม ถ้าจบได้ ชั้น 2 เป็นแค่ข้อมูลเพิ่ม ไม่ใช่การพลิก

เรื่องสั้นใช้ได้ทั้งชั้นเดียวหรือสองชั้น เรื่องยาวต้องมี **อย่างน้อยสองชั้น** (`twist.layers`) ส่วนการเฉลยย่อยทุก 2–3 นาทีตามกฎเรื่องยาวไม่นับเป็นชั้น เพราะไม่ได้เปลี่ยนคำถาม

## 3. รสหลักของเรื่อง (flavour)

ชื่อช่องเล่าหักมุมสัญญาว่าจะมีจุดพีค แต่จุดพีคไม่จำเป็นต้องเป็นการเปิดชื่อคนร้ายเสมอ เลือกรสหลักหนึ่งรสต่อเรื่อง และไม่ซ้ำสองเรื่องก่อนหน้า

| id | จุดพีคคือ | คนดูรู้สึก | ใช้บ่อยกับ |
|---|---|---|---|
| `shock` | ความจริงที่พลิกทุกอย่าง | ขนลุก ย้อนดู | `who`, `fake-ghost`, `time` |
| `dread` | คนดูรู้ก่อนตัวเอก แล้วต้องดูเขาเดินเข้าไป | ลุ้น ทนไม่ไหว | `rule-for`, `trap-exit` |
| `grief` | ความจริงที่เจ็บกว่าความกลัว | สะเทือนใจ | `what-lead`, `victim` |
| `clever` | ตัวเอกใช้กฎของโลกหักกลับ | สะใจ | `rule-for`, `trap-exit` |
| `choice` | ตัวเอกต้องเลือกหลังรู้ความจริง และราคามีจริง | เสียดาย นับถือ | `what-lead`, `whose-story` |

เรื่องที่รสหลักไม่ใช่ `shock` ยังต้องมีหักมุม แต่หักมุมนั้นอยู่ก่อนจุดพีค (เที่ยวสุดท้าย: หักมุมอยู่ที่ราว 70 % จุดพีคคือการเลือกขับต่อ)

## 4. โครงเรื่อง (structure)

โครงในกฎเรื่องยาวเดิม (คนร้ายอยู่ในเฟรมคอยช่วย, สนามผู้ต้องสงสัย, คำพูดหลุด, การจับกุม) คือโครง `hunt` ซึ่งเป็นโครงหนึ่งเท่านั้น ห้ามใช้ `hunt` ติดกันเกินสองเรื่อง

| id | รูป | กฎ Concealment ที่ใช้ |
|---|---|---|
| `hunt` | สืบหาคนร้าย: ผู้ต้องสงสัยหลายคน คำพูดหลุด หลักฐาน จับกุม | ครบ 9 ข้อ |
| `contract` | รับงานหรือข้อตกลงที่มีกฎ แต่ละกฎ "ทำงาน" ทีละคืน แล้วค่อยรู้ว่าสัญญาจริงคืออะไร (เที่ยวสุดท้าย) | ข้อ 1, 2, 6–9 ไม่บังคับให้มีสนามผู้ต้องสงสัย คนให้งานอาจซื่อสัตย์ก็ได้ |
| `irony` | บอกคนดูตั้งแต่ต้น (หรือที่ชั้น 1) ว่าตัวเอกไม่รู้อะไร แล้วลุ้นว่าเขาจะรู้ทันไหม | ไม่ซ่อนคำตอบหลัก ซ่อนเฉพาะชั้น 2 |
| `rule-game` | ตัวเอกเรียนกฎของสิ่งลี้ลับจริงทีละข้อ แล้วใช้กฎนั้นเอาชนะหรือต่อรอง | ไม่ต้องมีคนร้ายที่เป็นคน |
| `two-time` | สองเส้นเวลาเล่าสลับกัน แล้วมาบรรจบที่จุดพีค (`data.past`) | ซ่อนว่าเส้นไหนเกิดก่อน หรือเป็นคนเดียวกันไหม |
| `survival` | ภัยตามกฎ ตัวเอกต้องรอด (เป็นค่าเริ่มต้นของเรื่องสั้น "ถ้า…") | `story-rules.md` |

## 5. สิ่งลี้ลับ

`universe/bible.md` ข้อ 1 บอกว่าสิ่งลี้ลับในอำเภอนี้มีกฎและมีราคาเสมอ ข้อนี้อนุญาตให้ผีมีจริง ข้อ 4 ("ความผิดมักเป็นของคน") เป็นแนวโน้มที่สังเกตจากเรื่องเก่า ไม่ใช่กฎ ระบุใน `twist.supernatural` ว่าเรื่องนี้เป็นแบบไหน:

- `real`: สิ่งลี้ลับมีจริง ทำงานตามกฎ ส่วนหักมุมอยู่ที่กฎ ราคา หรือตัวเอง (เที่ยวสุดท้าย, temple-boy)
- `fake`: มีคนจัดฉาก (นับรวมในกฎหมุนเวียนข้อ 2)
- `ambiguous`: คำอธิบายทั้งแบบคนและแบบผีใช้ได้ทั้งคู่ และมีภาพสุดท้ายหนึ่งภาพที่คำอธิบายแบบคนอธิบายไม่ได้ ใช้ไม่เกิน 1 ใน 4 เรื่อง เพราะถ้าใช้บ่อย คนดูจะรู้สึกว่าเรื่องไม่จบ
- `none`: ไม่มีสิ่งลี้ลับ เป็นดราม่าหรืออาชญากรรมล้วน

## 6. วิธีส่งเฉลย

- **ให้ภาพพูดก่อน** แล้วเงียบหนึ่งจังหวะ (`hush`) จากนั้นจึงให้ผู้บรรยายพูดคำเฉลยหนึ่งประโยค เที่ยวสุดท้ายใช้ลำดับ: ซากรถ → คนเดินทะลุตัว → เวลาตายตรงกับนาฬิกาที่หยุด → "เขาเดินออกจากอุบัติเหตุ โดยทิ้งร่างของตัวเองไว้ข้างหลัง" ภาพทำให้คนดูรู้ก่อนเสียงครึ่งจังหวะ
- **ไม่ไล่เบาะแสก่อนจุดพีค** การทวนเบาะแส ("วิทยุที่ป้าบอกว่า…", "กลอนที่ป้าเขย่า…") ย้ายไปหลังจุดพีค แต่ละข้อไม่เกินหนึ่งบรรทัด และไม่เกิน 3–4 ข้อ ที่เหลือให้ภาพ mirror เล่าโดยไม่มีเสียงบรรยาย
- **ประโยคเฉลยไม่สรุปแทนคนดู** ประโยค "ป้าคือคนดูต้นทางให้โจร" อธิบายข้อเท็จจริง ส่วนประโยค "ป้าไม่ได้กลัวมัน ป้ารอมันอยู่ทุกคืน" ทำให้ฉากเก่าเปลี่ยนความหมาย ใช้แบบหลัง
- **หลังเฉลยต้องมีเรื่องเหลือ** อย่างน้อยหนึ่งฉากที่ตัวเอกทำอะไรสักอย่างกับความจริงนั้น (เลือก, เสียสละ, ใช้กฎ, ปล่อย) ไม่ใช่มีแค่ฉากตำรวจมาถึงกับการสารภาพ

## 7. การทดสอบ

`cold-read.md` มีสามด่าน: **ด่านฮุก** (ก่อนเขียนบท ทดสอบว่าเดาแนวได้จากชื่อเรื่องกับฮุกหรือเปล่า), **ด่านคนดูประจำ** (ผู้อ่านได้รู้หักมุมของห้าเรื่องล่าสุดก่อนเดา) และ **ด่านพลิก** (หลังเฉลย ฉากเก่าเปลี่ยนความหมายไปแค่ไหน) ส่วนด่านเดิมที่ตัดบทกลางเรื่องยังใช้เหมือนเดิม

## 8. ช่องใน story.json และ canon

```json
"twist": {
  "engine": "what-lead",
  "structure": "contract",
  "flavour": "choice",
  "supernatural": "real",
  "culprit": "none",
  "ending": "choice",
  "line": "คนขับที่รับงานส่งวิญญาณ ตายตั้งแต่ก่อนรับงาน",
  "layers": [
    { "at": 45, "flips": "ของในตู้คือวิญญาณคนจมน้ำ" },
    { "at": 72, "flips": "สัญญาจบเมื่อมีคนขับคนใหม่ และคนขับคนใหม่คือเขาที่ตายแล้ว" }
  ]
}
```

- `culprit` (บทบาทของคนร้ายตัวจริง): `helper` (คนที่คอยช่วย), `employer` (คนที่จ้างหรือให้งาน), `family`, `authority` (ตำรวจ, หมอ, พระ, ครู), `lead` (ตัวเอกเอง), `stranger`, `victim` (เหยื่อ), `none`
- `ending`: `justice` (จับได้ ความจริงเปิด), `choice`, `sacrifice`, `escape`, `loss`, `reunion`, `open`
- `line`: หักมุมหนึ่งประโยค ด่านคนดูประจำใช้ข้อความนี้ ไม่ใช่ข้อความจาก brief
- หลังผู้ใช้อนุมัติ outline หรือ brief ให้คัดลอก `twist` ไปไว้ที่ `universe/canon.json → episodes.<slug>.twist` ในรอบเดียวกับที่อัปเดต canon (CLAUDE.md กฎข้อ 17) `npm run story` อ่านเรื่องก่อนหน้าจาก canon ตามลำดับในไฟล์

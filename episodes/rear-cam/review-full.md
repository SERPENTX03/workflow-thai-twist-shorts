## A. ต้องแก้ (ข้อผิดพลาดที่คนดูจะจับได้)

**A1. เวลาหายไปหนึ่งวันตั้งแต่ CH5** (ข้อผิดพลาดของผม)
คืนที่สองจบที่ `อังคาร 02:20` แล้ว CH5 เปิดที่ `พุธ 05:20` พร้อมประโยค "ตีห้ายี่สิบ เจย์ยังไม่ได้นอน" ซึ่งคือ 27 ชั่วโมงต่อมา เท่ากับหายไปหนึ่งคืนโดยไม่มีออเดอร์
→ เลื่อน HUD ตั้งแต่ CH5 ถึง CH10 ถอยหลังหนึ่งวัน:

| ช่วง | เดิม | แก้เป็น |
|---|---|---|
| CH5 | พุธ 05:20 | อังคาร 05:20 |
| CH6 | พุธ 10:00 / 10:40 | อังคาร 10:00 / 10:40 |
| CH7 | พุธ 23:40 / พฤหัส 01:30 / 02:40 | อังคาร 23:40 / พุธ 01:30 / 02:40 |
| CH8 | พฤหัส 02:45 / 04:00 | พุธ 02:45 / 04:00 |
| CH9 | ศุกร์ 00:40 – 02:02 | พฤหัส 00:40 – 02:02 |
| CH10 | ศุกร์ 06:10 | พฤหัส 06:10 |

บทที่ต้องแก้ตาม:
- ช็อต 242 "เหลือเวลาอีกสองวัน ถึงเย็นวันเสาร์" → *"เหลือเวลาถึงเย็นวันเสาร์นี้นะคะ"*
- ช็อต 277 "ในป่าช้าเมื่อสองคืนก่อน" → *"ในป่าช้าเมื่อคืนก่อน"*
- ช็อต 289 "คืนวันพฤหัส เจย์ไม่ได้นอนอีกคืน" → *"คืนวันพุธ..."*
- ช็อต 304 "ตอนตีสองของคืนวันพฤหัส" → *"คืนวันพุธ"*
- continuity ใน brief

กำหนดเย็นวันเสาร์ยังถูก: ส่งของ 4 คืน (จ. อ. พ. พฤ. ตอนเช้ามืด) และเงินนำจับได้เช้าวันพฤหัส ก่อนกำหนดสองวัน

**A2. ตำรวจซุ่มในทางลัดคืนที่สาม แล้วทำไมไม่จับพี่ชาติตอนนั้น** (ช็อต 334)
คนดูจะถามทันที → เพิ่มหนึ่งประโยคในแฟลชแบ็กของหมวดธีร์ ซึ่งยังทำให้ฉากที่ปั๊มใน CH7 มีเหตุผลด้วย:
- ช็อต 334 *"คืนที่ด่านว่าง ทีมผมซุ่มอยู่ในทางลัด / แต่รถดับไฟคันนั้นหลุดมือเราไปในความมืด"*
- ช็อตใหม่ *"ผมเลยไปรอที่ปลายทาง... ที่ปั๊ม"* (ภาพ: หมวดธีร์เดินออกจากประตูสังกะสีหลังปั๊ม มุมเดียวกับช็อต 33)
- ผล: หมวดธีร์ไปโผล่ที่ปั๊มตอนตีสองสี่สิบ (ช็อต 258–260) เพราะตามรถคันนั้นมา ไม่ได้มาเที่ยว

**A3. ผีอยู่ "บนทางลัด" หรือ "ที่โค้งหน้าศาลา"** (ช็อต 70 กับ 73, 222)
พี่ชาติพูดว่า "ทางนั้น{ผีแรง} ไรเดอร์ตายมาแล้วคนหนึ่ง" (หมายถึงทางลัด) แต่ตำนานที่เขาเล่าเอง และป้ายของต้อม บอกว่าตายตรงโค้งหน้าศาลา
→ เปลี่ยนจากจุดบกพร่องเป็นเบาะแส: พี่ชาติ**ย้ายผีไปไว้บนทางลัดเอง**เพื่อกันไรเดอร์ไม่ให้ใช้ทางของเขา เพิ่มหนึ่งช็อตหลังช็อต 227 ใน CH6:
- *"แต่พี่ชาติบอกว่าไรเดอร์คนนั้นตายบนทางลัด / ทั้งที่ป้ายของต้อมอยู่ตรงนี้"*
- ทวนอีกครั้งตอนการ์ดพลิกกฎข้อ 3 (ไม่ต้องเพิ่มช็อต)

**A4. "เป็นครั้งแรก ที่เจย์หันกลับไปมองศาลาหลังนี้"** (ช็อต 360)
ไม่จริง ใน CH6 เจย์ยืนดูศาลาตอนกลางวันมาแล้ว สิ่งที่ไม่เคยทำคือหันกลับไปมองตอนขี่ออก
→ *"ก่อนออกจากศาลา เจย์หันกลับไปมอง / เป็นครั้งแรก ด้วยตาของตัวเอง"* ภาพเป็นเจย์บนรถหันหน้ากลับไปทางศาลา (ไม่ใช่ยืนหันหน้าตรง)

## B. ควรแก้

**B1. มือในร้านข้าวต้มไม่มีใครปิดเรื่อง** (ช็อต 102 "นิ้วผอมซีด")
ภาพที่น่ากลัวที่สุดของคืนแรกไม่เคยถูกเฉลย → ช็อต 351 เปลี่ยนเป็น *"ตำรวจค้นร้านข้าวต้มในเมือง / และกำลังขยายผลไปถึงผู้ว่าจ้าง"* (ภาพ: ประตูเหล็กร้านข้าวต้มถูกเปิดขึ้นสุดในแสงเช้า มีตำรวจยืนอยู่ในร้าน)

**B2. เสียงนอกจอสามคนใช้ `young_female` ตัวเดียว**
ผู้ประกาศข่าว (140–141), พนักงานไฟแนนซ์ (242) และศูนย์วิทยุตำรวจ (150, 350–351) เป็นเสียงเดียวกัน → ย้ายศูนย์วิทยุตำรวจไปใช้ role `female` (HammyTH) ให้คนฟังแยกออก ยังอยู่ในเพดาน 6 เสียง

**B3. ประโยคหักมุมช้าไปนิด (93%)**
ไฟตำรวจมาที่ 90% ตรงเป้า แต่ red box 3 อยู่ที่ 93% → รวม 289–291 (เตรียมตัวในห้อง) เหลือสองช็อต และรวม 294–296 (กล่องที่สี่ + ด่านว่าง) เหลือหนึ่งช็อต จะประหยัดได้ราว 12 วินาที เหลือประมาณ 92% ส่วนที่เหลือรอดูหลังทำเสียงจริง

**B4. องก์ 1 ยาว (คืนแรกเริ่มที่ 6:56 = 27%)**
ข้อ 8 ของรีวิว CH0–2 (ตัดหรือรวม 3 ช็อตใน CH1) ยังใช้ได้ ช่วยดึงคืนแรกมาที่ราว 6:40

**B5. ทำไมหมวดธีร์จะเปิดกล่องคืนที่สอง ถ้าตั้งใจปล่อยให้ผ่าน** (ช็อต 333)
ตอนนี้แฟลชแบ็กพูดเหมือนเขาตัดสินใจเองว่าไม่เปิด แต่จริงๆ เขาเกือบเปิดแล้วถูกวิทยุเรียกไป → *"คืนที่ผมเกือบกรีดเทป / ถ้าเปิดได้คืนนั้น ผมจะได้แค่ไรเดอร์คนเดียว"* แล้วต่อด้วย *"วิทยุเรียกผมไปพอดี... ผมเลยเปลี่ยนแผน"*

## C. จากรีวิว CH0–2 ที่ยังไม่ได้แก้

| ข้อ | สถานะตอนนี้ |
|---|---|
| 4 พี่ชาติเข้าออกประตูหลังปั๊ม | **บางส่วนแก้เองแล้ว** ช็อต 239 แสดงว่าหลังปั๊มเป็นที่จอดรถของคนในวินห้าคัน การเข้าออกประตูหลังจึงดูปกติ แต่ใน CH1–2 ยังไม่มีใครพูดถึง ใส่หนึ่งบรรทัดตอนพี่ชาติเข็นรถออก (ช็อต 91) ก็พอ |
| 5 ทำไมพี่ชาติไม่สั่งปิดกล้องหน้า | สำคัญขึ้น เพราะ CH9 ใช้กล้องหน้าเป็นหลักฐานชิ้นสุดท้าย ("กล้องหน้าผมยังไลฟ์อยู่") ประโยค *"กล้องหน้าเอ็งจะอัดก็อัดไป... ผีมันอยู่ข้างหลัง"* จะกลายเป็นคำพูดที่ย้อนกลับมาเล่นงานพี่ชาติเอง |
| 6 กฎข้อ 2 ควรห้ามไลฟ์ | การ์ดขีดฆ่าใน CH9 (ช็อต 293) พูดว่า "ห้ามถ่ายรูป ห้ามแชร์" ซึ่งพอใช้ได้ แต่ถ้ากฎตั้งแต่ CH2 เขียนว่า "ห้ามไลฟ์" ตรงๆ จะชัดกว่า |
| 7 ปูด่านตำรวจ | ช็อต 115 "รถส่งอาหารไม่ต้องเปิดกล่อง" ปูไว้แล้วบางส่วน |
| 8 CH1 ยาว | ดู B4 |
| 9 เสียงบรรยากาศที่ปั๊ม | **แก้แล้ว** ใส่ sfx `station` ไว้ใน CH3 แล้ว ใช้ซ้ำใน CH1–2 ได้ |

## ผ่านแล้ว

- **โครงเรื่อง:** cold open (0:00) → title → ปูโลก → กฎ → คืนแรก (27%) → คืนที่สอง → **จุดกลางเรื่อง 50%** (red box 1) → สงสัยผิดคน A (ลุงเหม) แล้วพ้นข้อสงสัย → สงสัยผิดคน B (หมวดธีร์) → **คำหลุดปาก 78%** (red box 2) → พวงกุญแจ 79% → **ไฟตำรวจ 90%** → red box 3 + `bighit` 93% → บทส่งท้าย 1:09 → end card
- **ทุกเบาะแสมีภาพจ่ายคืน** ตรงตารางใน brief: พวงกุญแจ, เทปรอบที่ 4, กล้องหลังเสียแล้วซ่อม, สมุดดำ, รอยยาง/บู๊ต/ถุงมือ, รถบรรทุกตีสาม, ต้อม, เพจ 312 → 313
- **ทดสอบความแฟร์:** พี่ชาติอยู่บนจอตั้งแต่ CH1 ใจดีกับเจย์ ทุกฉากที่มีเขายังอ่านได้ทั้งสองแบบหลังเฉลย เช่น "ไม่ได้หันไปดูนะ", "ก็ลุงเหมไง", บู๊ตโคลน, ไม่อยู่ที่ปั๊มคืนที่สอง
- **จุดบอดตามกฎ:** ไม่มีใครตาย, ตัวเอกไม่ทำเรื่องโง่ (ไปป่าช้าตอนกลางวัน, ใช้ไลฟ์เป็นประกัน, ไม่ลงจากรถ), โลกไม่สุญญากาศ (ข่าว ด่าน ไฟแนนซ์ รถบรรทุก), พี่ชาติพังทลายด้วยความละอายหลังถูกจับ, ตอนจบได้ชัยชนะทางใจ (ทองครบ เจย์รักษารถไว้ได้ ต้อมได้รับการรำลึก)
- **ความชัดเจน:** ทุกการกระทำแปลกมีเหตุผลประกบ (รับงานต่อเพราะเงินและกลัวถูกจับได้, ไม่โทร 191 เพราะชื่อตัวเองอยู่ในสมุด) และเบาะแสที่กลับมาตอนท้ายมีคำขยายช่วยจำ ("เทปรอบที่สี่ ที่เจย์พันด้วยมือสั่นๆ ในป่าช้า")
- **ความเงียบ:** 0.3% ของเรื่อง ไม่มีช็อตว่างติดกัน
- **คนพูดเท่านั้นที่ขยับปาก:** เสียงวิทยุ โทรศัพท์ เสียงในใจ และเสียงนอกเฟรม ไม่มี `talk` บนจอ
- **red box 3 ครั้ง** และ `bighit` ครั้งเดียว ตรงที่หักมุม
- **ประโยคของผู้ใช้จากต้นฉบับยังอยู่ครบ:** "มึงแค่รับเงิน 850...", "หยุดอยู่ตรงนั้น ชาติ!", red box ทั้ง 3, ประโยคปิดเรื่อง

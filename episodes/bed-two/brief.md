# พยาบาลเวรดึก ชั้นสี่ตึกปิด — brief

Landscape 16:9, long-form (~23 min, `target` [1320, 1500]), true-crime style fiction ปนบรรยากาศหลอน (ผีเป็นแค่เครื่องมือ ภัยจริงเป็นคน), โรงพยาบาลคลองหมอก ตึกเมตตา ชั้น 4 (ปิดปรับปรุง), สามคืนติดกัน + เช้าวันที่สี่. All events, the hospital, its board, the police and the land office are fiction; title card + end card say so. ไม่วาดโลโก้หรือชื่อโรงพยาบาล/กระทรวงจริง ยาใช้ชื่อสามัญ (vecuronium) ไม่มีชื่อการค้า

ที่มา: prompt ของเจ้าของเรื่อง (พยาบาลเวรดึก: ตึกผู้ป่วยชั้นปิดปรับปรุง) ปรับตาม audit + fun pass ที่เจ้าของอนุมัติทั้งหมด 2026-11-12

**Logline:** พยาบาลจบใหม่รับจ้างเฝ้าไข้โคม่าคืนละห้าพันบนชั้นสี่ตึกที่ปิดปรับปรุง ภายใต้กฎ 5 ข้อที่ห้ามเปิดม่านเตียงสอง จนพบว่ายาที่เธอฉีดทุกชั่วโมงทำให้คนไข้ตื่นอยู่แต่ขยับไม่ได้
**Twist:** คนบนเตียงหนึ่งคือ ผอ.วรเทพ ที่ทั้งประเทศเชื่อว่าหนีไปพร้อมเงินยา 80 ล้าน เตียงสองไม่มีผี มีแค่ลำโพงกับมือถือที่หัวหน้าเวรใช้เฝ้าดูเธอ และพรุ่งนี้ 08:30 ลายนิ้วมือของเขากับลายเซ็นพยานของเธอจะปิดคดีไปตลอดกาล
**Tracked device:** กฎ 5 ข้อ — HUD `กฎข้อ n / 5` ทุกครั้งที่ข้อหนึ่งถูกทำตามหรือถูกฝ่า (ตราประทับ ✓ / ✗ บนใบกฎ) พร้อมนาฬิกา HUD และ "เข็มที่ n"

1. ฉีดยาตามเวลาทุกชั่วโมง ห้ามข้าม
2. ห้ามเปิดม่านเตียงสองเด็ดขาด
3. หลังตีสาม อย่าขานรับเสียงเคาะประตูกระจกหน้าวอร์ด
4. ห้ามแกะเทปปิดตาคนไข้ (คนโคม่าหลับตาไม่สนิท กระจกตาจะแห้งเป็นแผล)
5. ถ้าคนไข้ขยับ ให้ฉีดเข็มถัดไปทันที ไม่ต้องรอเวลา (คนโคม่ากระตุกได้)

ลำดับที่กฎถูกใช้: ข้อ 3 ทำตาม (คืน 1) → ข้อ 5 ทำตาม (คืน 2, ขนลุกเมื่อดูซ้ำ) → ข้อ 4 ฝ่า (midpoint) → ข้อ 1 ฝ่า (บท 5) → ข้อ 2 ฝ่า (บท 6) → ข้อ 3 ฝ่าแบบไม่เปิดประตู แต่หนี (บท 6–7) · งานจริงของแต่ละข้อ เมย์คลี่เองกลางเรื่อง ไม่ใช่สรุปรวมตอนจบ (ต่างจาก `night-shift-rules`)

| ทำไมจ้างพยาบาลจบใหม่ | ไม่ชัด | ต่างถิ่น มีหนี้ ไม่กล้าถาม ไม่รู้จักหน้า ผอ. และลายเซ็นของเธอในบันทึกการฉีดทุกชั่วโมง + ลายเซ็นพยานในหนังสือมอบอำนาจ ทำให้เธอเป็นแพะ ถ้าเขาตาย คนฉีดคือเธอ |
| กล้องจิ๋ว + ดูผ่านมือถือ | เมย์เข้าระบบกล้องได้ยังไง | หลังม่านเตียงสองมี **มือถือเก่าเทปติดเสาน้ำเกลือ เปิดวิดีโอคอลค้างไว้** กับ **ลำโพงบลูทูธ** (ไฟแดงกะพริบ = ไฟของลำโพง) เมย์กระชากม่านแล้วเห็นจออีกฝั่งของสาย: นวลกับทนายกำลังเดินขึ้นทางลาด |
| "ใช้ความรู้แก้ทางยาพิษ" | ไม่ระบุ | หยุดฉีด · ดูแลเครื่องช่วยหายใจเอง · ไฟดับ → vent ใช้แบตสำรอง ~30 นาที (เดา) → บีบแอมบูทุก 5 วินาที · นีโอสติกมีน + อะโทรปีนจากรถเข็นฉุกเฉินเก่า (เช็กวันหมดอายุบนจอ) |
| ข่าว ผอ. หายตัว | cold read รอบ 1: คนอ่านเดาว่า "คนไข้คือ ผอ." อันดับ 1 ที่ 50 % | **คลิปขอโทษ ผอ. ส่งมาจากต่างประเทศ** ("ผมขอโทษ ผมรับผิดเอง ผมจะไม่กลับไป") อัดคืนที่เขาถูกพาขึ้นชั้นสี่ ก่อนเริ่มยา ฉากหลังของคลิปเป็นม่านลายเดียวกับม่านเตียงสอง — **ภาพเท่านั้น ห้ามพูดถึงสีหรือลายของม่าน** |
| ไม่มีตัวตน "ญาติ" | cold read: งงว่าญาติคือใคร และคนดูไม่มีคำตอบผิดให้ยึด | **แพร ลูกสาวปลอม** + ประวัติปลอม "พ่อเป็นผู้รับเหมา ตกนั่งร้านตึกนี้เอง" + รูปชายใส่หมวกนิรภัยข้างเตียง |
| ทนายความตระกูล | ไม่มีตระกูลจริงในเรื่อง | ทนายปกรณ์ "ทนายของญาติ" |
| อักษรแรกของชื่อ ("ว") | cold read: ชี้ตัวตน | คนไข้กะพริบสะกดว่า **"ห-น-ี"** (เตือนให้หนี ไม่บอกว่าเป็นใคร) |
| ผู้ต้องสงสัยมีแค่หัวหน้าเวร + ทนาย | ผิด Concealment ข้อ 3 | เพิ่มหมอต้น ลุงพร แพร แต่ละคนมีความลับจริง คำโกหก tell และเฉลยท้ายเรื่อง |

ความซ้ำที่ต้องระวัง: `dont-open-curtain` (ห้ามเปิดม่าน · ตีสาม · เสียงเคาะ = คนขอชีวิต) และ `night-shift-rules` (คนผิดเขียนกฎ) — ชื่อคลิป/ปก **ห้ามใช้คำว่า "ม่าน"** ให้ใช้ "เตียงสอง" / "กฎเฝ้าไข้"
